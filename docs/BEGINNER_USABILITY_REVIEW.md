# 초심자 적용·편집성 재검토

검토일: 2026-08-14

## 결론

수정 전 저장소는 초심자가 바로 적용하고 편집할 수 있는 상태가 아니었습니다. 개발 검증, 내부 권한 용어, 교사 명령, Copilot 관리 절차가 첫 문서에 섞여 있었고, `pnpm teacher --` 방식의 인수 전달도 실제 pnpm 실행에서 실패했습니다. Copilot 폴더는 선언형 에이전트 정의만 있었으며 업로드용 Microsoft 365 앱 패키지는 없었습니다.

이번 수정 뒤 ChatGPT 일반 대화 체험과 대화 단위 학급 설정은 초심자가 따라 할 수 있는 별도 경로를 갖습니다. 그러나 지속형 학급 포크는 여전히 명령줄 기반 고급 기능이고, Copilot은 학교 IT 관리자용 완성 패키지와 실제 테넌트 검증 전까지 배포 보류입니다.

## 초심자 사용자

### 교사

- Git, JSON, Node.js, 터미널을 모를 수 있습니다.
- 5분 안에 수업 체험을 시작하고 싶습니다.
- 학생 개인정보를 넣지 않고 학년·과목·표현만 고치고 싶습니다.
- “저장됨”, “검증됨”, “배포 가능”이라는 말이 정확히 무엇을 뜻하는지 알아야 합니다.

### 학교 IT 관리자

- 교과 설계자가 아닐 수 있습니다.
- Microsoft 365 테넌트 정책, 앱 패키지, 조직 배포 범위만 명확히 확인하고 싶습니다.
- 선언형 에이전트 JSON 통과와 실제 업로드 가능 상태를 혼동하면 안 됩니다.

## 사용자 여정

| 단계 | 수정 전 | 현재 |
|---|---|---|
| 첫 파일 선택 | 개발자용 README부터 읽어야 함 | `START-HERE.md`에서 역할 선택 |
| ChatGPT 체험 | 지침 파일 위치를 스스로 찾아야 함 | 복사 순서와 기대 동작을 3단계로 안내 |
| 교사 편집 | 긴 명령줄 또는 GPT Builder 내부 파일 편집 | 대괄호만 고치는 학급 설정표 제공 |
| 교사 명령 도움말 | 빈 호출과 `--help`가 오류로 종료 | 빈 호출과 `--help`가 명령·예시 표시 |
| pnpm 명령 | 문서의 `pnpm teacher -- ...`가 실제로 실패 | 선행 `--`를 정상 처리하는 회귀 추가 |
| Copilot | 스키마 통과를 설치 가능으로 오해할 수 있음 | 진단 명령이 누락 파일과 배포 보류를 표시 |
| Windows | 기능 설명과 현 베타 범위가 혼재 | 첫 안내에서 명시적으로 보류 |

ChatGPT 일반 대화의 목표 시작 시간은 5분 이내입니다. Copilot은 현재 시작 시간으로 평가할 수 없으며 설치 차단 상태입니다.

## 이번에 반영한 수정

- 학생·교사·학교 IT 관리자 경로를 분리한 최상위 `START-HERE.md`
- 대괄호 안만 수정하는 `chatgpt/CLASSROOM_SETTINGS.example.md`
- 교사가 편집해도 되는 항목과 불변 항목을 나눈 `chatgpt/TEACHER-QUICK-START.md`
- 학급 설정을 현재 대화의 기본값 후보로만 적용하고 개인정보·안전·사실 검증을 우선하는 ChatGPT 지침
- 학교 IT 관리자용 `copilot/IT-ADMIN-QUICK-START.md`
- 누락된 앱 manifest와 아이콘을 보이는 `pnpm copilot:doctor`
- 빈 교사 명령과 `--help`의 성공 처리, 실제 pnpm의 선행 `--` 호환
- 초심자 경로, 도움말, Copilot fail-closed 판정을 고정하는 자동 회귀 테스트

## 아직 “바로 적용 가능”이라고 말하면 안 되는 부분

- 공유받은 Custom GPT를 교사가 자동으로 복제·편집하는 기능
- 개인 ChatGPT 계정에서 새 GPT 생성 권한을 보장하는 설명
- 교사 학급 설정의 대화 간 자동 영구 보존
- 무설치 그래픽 화면을 통한 지속형 학급 포크 생성
- Microsoft 365 앱 manifest·아이콘·ZIP을 포함한 Copilot 설치 패키지
- 실제 Copilot Enterprise/Education 테넌트 동작
- Windows 독립 실행본

## 다음 검증과 수정 기준

1. 이 저장소를 처음 보는 교사 3명이 도움 없이 ChatGPT 일반 대화를 5분 안에 시작하게 합니다.
2. 세 교사가 학급 설정표에서 학생 개인정보 없이 과목·단원·표현 규칙을 바꾸게 합니다.
3. 잘못된 학교급 입력, 학급 설정에 섞인 안전 해제, 근거 없는 사실 정정을 넣고 설명이 이해되는지 기록합니다.
4. 한 명이라도 파일 선택이나 붙여 넣기 순서를 묻는다면 첫 문서를 수정합니다.
5. 지속형 학급 포크 수요가 확인되면 명령줄을 숨기는 로컬 설정 화면을 별도 제품으로 설계합니다. Windows 버전 보류가 해제되기 전에는 구현 완료로 표시하지 않습니다.
6. Copilot은 앱 패키지를 만든 뒤 학교 IT 관리자와 실제 테넌트에서만 설치성을 평가합니다.

## 배포 판정

- ChatGPT 일반 대화 초심자 체험: 문서·회귀 수준에서 조건부 가능
- 교사의 대화 단위 간단 편집: 문서·회귀 수준에서 조건부 가능
- 지속형 학급 포크: 개발·평가용, 초심자 배포 보류
- Microsoft 365 Copilot: 배포 보류
- Windows: 배포 보류

자동 회귀 통과만으로 교사 사용성이나 실제 서비스 권한을 입증했다고 말하지 않습니다.
