# 초심자 교사·IT 관리자 사용성 감사

기준일: 2026-08-14

## 실제 명령 측정

| 경로 | 결과 | 측정 시간 |
|---|---|---:|
| `pnpm teacher` | 역할·명령·가장 짧은 확인·쉬운 대안 표시, 종료 0 | 0.908초 |
| `pnpm teacher -- --help` | 같은 도움말 표시, 종료 0 | 0.855초 |
| 잘못된 교사 명령 | 초기에는 JSON 오류와 패키지 오류가 섞임 | 0.861초 |
| 수정 뒤 잘못된 교사 명령 | `오류:`와 도움말 명령을 국문으로 표시, 종료 1 | 회귀 시험 통과 |
| `pnpm copilot:doctor` | 로컬 ZIP과 실제 테넌트 시험을 분리 | 0.863초 |
| `pnpm copilot:tenant-doctor` | 로그인·관리자 정책·ZIP을 분리해 정책 차단 표시 | 13.667초 |

교사 기본 경로는 명령줄이 아니다. `START-HERE.md` → `chatgpt/CLASSROOM_SETTINGS.example.md`의 대괄호만 수정 → 비공개 수업 시험이 가장 짧은 경로다. Microsoft 365 설치는 학교 IT 관리자 경로로 분리했다.

종합: 6.6/10. 명령 자체의 첫 성공은 2분 이내지만, Microsoft 365 경로는 관리자 정책이 필수라 일반 교사의 자가 설치 경로로 평가하면 안 된다.

GStack가 지시한 Hall of Fame 보조 파일은 이 설치의 skill 디렉터리에 존재하지 않아 해당 비교 기준은 적용하지 못했다. 점수는 실제 명령 출력과 저장소 문서를 근거로 한 현재 감사값이다.

## 수정 완료

1. 잘못된 교사 명령이 JSON만 출력하던 문제를 쉬운 국문 오류와 다음 명령으로 수정했다.
2. Microsoft 365 정책 차단을 설치 전에 확인하는 `copilot:tenant-doctor`를 추가했다.
3. Windows를 건드리지 않는 `export:active`, `verify:exports:active` 경로를 추가했다.
4. 개인정보·비공개 식별자·위해 세부를 받지 않는 연구·교사 검수 양식을 추가했다.

## 남은 검증

실제 초심자 교사 최소 3명에게 화면 공유 없이 첫 수업 준비를 맡기고 완료 시간, 막힌 문구, 잘못된 개인정보 입력 시도, 도움 요청 횟수를 관찰한다. 한 명이라도 Microsoft 365 설치를 교사 업무로 오해하면 시작 문서의 역할 분리를 다시 수정한다.
