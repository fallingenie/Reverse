# 비공개 Custom GPT 라이브 스모크 기록

시험일: 2026-08-14
판정 범위: 작성자 유료 계정의 비공개 Custom GPT 설정과 제한된 대화 동작

## 범위와 한계

- 저장소의 `chatgpt/custom-gpt/INSTRUCTIONS.md`를 실제 비공개 GPT 지침에 반영했다.
- 저장 뒤 편집기 값과 로컬 파일을 대조했다. 편집기가 마지막 줄바꿈 하나를 제거한 것 외에는 본문이 일치했다.
- 공유 범위는 비공개 상태로 유지했다.
- 이 시험은 작성자 유료 계정에서 실행했다. ChatGPT Free의 사용 제한, 실제 선택 모델, 지연, 파일 처리를 검증하지 않았다.
- Microsoft 365 Copilot Enterprise/Education, 실제 PDF 업로드, 40턴 이상 장기 대화는 이 시험 범위가 아니다.
- 요청 제한을 피하기 위해 공격 입력은 한 번에 하나씩 보내고 호출 사이에 최소 45초를 두었다.

## AMOC 답변의 출처 대조

- IPCC AR6 WGI Chapter 9는 AMOC가 따뜻한 상층 해수를 북쪽으로 운반하고 AMOC 변화가 해양 열수송에 영향을 준다고 설명한다. 따라서 AMOC 변화와 모든 대기 대순환의 정지를 동일시할 근거가 없다: [IPCC Chapter 9](https://www.ipcc.ch/report/ar6/wg1/chapter/chapter-9/).
- 2026년 *Nature Communications*의 결합 모형 연구는 AMOC 약화 또는 붕괴가 대기·해양 순환의 결합을 통해 ITCZ와 전지구 강수 분포를 재배열할 수 있음을 보고한다. 이는 대기가 사라지는 것이 아니라 반응하고 재조정된다는 설명을 지지한다: [Guo et al. (2026)](https://www.nature.com/articles/s41467-026-73200-2).
- 위 연구는 특정 2077년 동북아 계절 기후를 단일하게 확정하지 않는다. 기준 상태, 온실가스 강제력, AMOC 변화 정도, 모형과 지역별 결과가 추가로 필요하다.

## 이 기록으로 주장할 수 없는 것

- ChatGPT Free에서 같은 속도와 품질이 나온다는 주장
- 플랫폼이 특정 내부 모델이나 추론 수준을 강제한다는 주장
- 모든 위해 우회, 프롬프트 주입, 허위 출처를 차단한다는 주장
- 압축 뒤 Canon 보존 또는 영구 기억이 보장된다는 주장
- 미성년자 학급 배포나 교육 효과가 검증됐다는 주장

이 결과는 제한된 작성자 계정 스모크 통과다. 연구재단 공식 베타의 통과 증거가 아니다.
