## 확인된 결함

### 1. HIGH — GitHub Actions가 이동 가능한 태그에 고정됨

- 신뢰도: 9/10
- 상태: 확인됨
- 위치: `.github/workflows/ci.yml` 25~33행
- 직접 근거: `actions/checkout@v4`, `pnpm/action-setup@v4`, `actions/setup-node@v4`, `actions/setup-python@v5`
- 공격 경로: 공급망 또는 태그가 변조되면 다음 CI가 변경된 Action 코드를 저장소 읽기 토큰과 빌드 작업공간의 범위에서 실행한다.
- 영향: CI 결과·로그·산출물 무결성이 훼손될 수 있다. `contents: read`는 피해 범위를 줄이지만 실행 코드 자체는 보호하지 않는다.
- 수정: 공식 저장소의 확인된 전체 커밋 SHA에 고정하고 사람이 읽을 수 있는 버전을 주석으로 남긴다.

## 남은 구조적 위험

- Custom GPT와 Copilot은 프롬프트 수준 방어다. 웹·PDF의 간접 프롬프트 주입을 완전 차단하거나 핵심 설정의 영구 보존을 보장할 수 없다.
- Copilot Studio 미리보기 통과는 Microsoft 365 Copilot 실제 런타임 통과와 같지 않다.
- `SECURITY.md`에 기관의 비공개 신고 채널이 아직 구체적으로 지정되지 않았다. 문서 자체 규칙에 따라 이 상태에서는 외부 베타를 시작하면 안 된다.
- 플랫폼 계약·테넌트 데이터 보호·대화 보존 설정은 저장소가 강제하지 못한다. 연구 시작 전에 기관 관리자가 따로 확인해야 한다.
