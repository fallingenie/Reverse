# 초심자 교사·IT 관리자 사용성 재검증 2차

검증일: 2026-08-14

## 판정

`pnpm start` 하나로 ChatGPT와 Microsoft 365 Copilot의 로컬 준비 상태를 구분해 확인할 수 있게 했다. ChatGPT는 파일 무결성까지만, Copilot은 기본 실행에서 로컬 ZIP까지만 판정한다. Microsoft 365 계정과 조직 정책은 학교 IT 관리자가 명시적으로 `--tenant`를 붙였을 때만 조회한다.

이 개선은 무설치 프로그램이 아니다. Node.js와 pnpm이 이미 설치된 저장소 검수자를 위한 단일 진입점이다. 일반 교사가 복사·붙여넣기 없이 ChatGPT를 사용하는 경로는 접근 권한을 받은 비공개 공유 GPT뿐이다. 이 저장소가 GPT를 자동 생성·공유하거나 Microsoft 365 앱을 자동 설치·게시한다고 표시하지 않는다.

## 수정 전 실제 마찰

1. 최상위 패키지에 첫 실행 명령이 없어서 `pnpm run` 목록에서 여러 진단 명령을 직접 골라야 했다.
2. ChatGPT에는 로컬 배포물의 현재 해시와 필수 파일을 한 번에 확인하는 초심자용 명령이 없었다.
3. Copilot은 로컬 패키지 점검과 테넌트 점검이 분리돼 있었지만, 처음 보는 교사가 어느 단계에서 멈춰야 하는지 명령 자체에서 바로 알기 어려웠다.
4. 기존 테넌트 진단은 계정 식별자를 출력했다. 새 초심자 진입점은 로그인 여부만 표시하고 계정 문자열은 반복하지 않는다.

## 새 진입점

```text
pnpm start
pnpm start -- chatgpt
pnpm start -- copilot
pnpm start -- copilot --tenant
```

- 인수 없는 실행: 역할별 번호와 정확한 다음 명령만 표시한다.
- `chatgpt`: 시작 지침, 학급 설정표, Custom GPT 지침, 배포 해시, LICENSE·NOTICE를 확인한다. 실제 ChatGPT 응답 통과는 별도라고 표시한다.
- `copilot`: 계정이나 테넌트를 조회하지 않고 로컬 앱 패키지만 확인한다. ZIP 존재만 보지 않고 현재 소스로 다시 계산한 바이트와 비교하며, 일반 교사에게 중단선을 표시한다.
- `copilot --tenant`: 학교 IT 관리자 경로로 로그인, 허용된 조직 도메인, 조직 업로드 정책을 읽기 전용으로 확인한다. 지원 대상은 `한국과학창의재단`, 환경 ID는 `9324e73a-cd4e-e049-b7ba-177af6165e9c`로 고정하며 실제 Studio 화면의 ID는 관리자가 직접 대조해야 한다. 앱 설치·업로드·정책 변경은 하지 않는다.
- `--strict`: 자동화에서 준비되지 않은 상태를 종료 코드 2로 받는다. 사람용 기본 진단은 차단을 정상적으로 발견한 경우 종료 코드 0으로 끝나 pnpm 패키지 오류를 섞지 않는다.

## 실제 측정

| 명령 | 결과 | 시간 |
|---|---|---:|
| `pnpm start` | 역할별 메뉴, 자동 설치 불가 경계, 종료 0 | 0.694초 |
| `pnpm start -- chatgpt` | 필수 파일·현재 해시·LICENSE·NOTICE 확인, 라이브 미검증 표시, 종료 0 | 0.607초 |
| `pnpm start -- copilot` | 현재 소스와 ZIP 바이트 일치 확인, 일반 교사 중단선 표시, 종료 0 | 0.592초 |
| `pnpm start -- copilot --tenant` | 조직 도메인 확인, 관리자 업로드 정책 차단, 환경 ID 수동 대조 요구, 계정 문자열 미표시, 종료 0 | 11.655초 |

테넌트 결과는 `조직 정책이 사용자 지정 앱 업로드를 허용하지 않습니다`였다. 이는 진단 성공이지 설치 성공이 아니다. 실제 에이전트 실행은 계속 미검증이며 Microsoft 365 경로는 배포 보류다.

위 시간은 2026-08-14의 현재 로컬 작업 트리에서 한 번씩 측정한 값이며 초심자 수행시간이나 성능 보장이 아니다. 커밋 단위 재현 증거는 [로컬 자기검증 안내](../LOCAL-SELF-ATTESTATION.md)의 별도 clean-checkout 묶음으로 기록하며, 그 결과도 GitHub Actions 통과로 간주하지 않는다.

## 회귀 검증

신규 Node 회귀는 다음을 고정한다.

1. 첫 메뉴가 ChatGPT, Copilot, IT 관리자 전용 테넌트 명령을 구분하고 번호 `1`, `2`, 빈 입력, 잘못된 입력의 분기 로직을 검사한다. 실제 TTY 키입력 관찰과는 구분한다.
2. ChatGPT 로컬 배포물의 파일 해시가 현재 manifest와 일치한다.
3. ChatGPT 로컬 통과를 라이브 응답 통과로 표현하지 않는다.
4. Copilot 기본 경로는 테넌트 진단을 호출하지 않는다.
5. 명시적 테넌트 경로가 정책 차단을 건조한 한국어로 표시하고 계정 식별자를 반복하지 않는다.
6. 엄격 모드는 정책 차단을 종료 코드 2로 반환한다.
7. 존재하지 않는 자동 설치 옵션은 지원하지 않는다고 표시한다.
8. 하위 경로 뒤의 `--help`도 외부 점검을 시작하지 않고 첫 메뉴를 보여준다.
9. ChatGPT 파일이 manifest 작성 뒤 바뀌면 로컬 준비 상태를 실패 폐쇄한다.
10. Copilot 로컬 ZIP이 없으면 `--tenant` 요청이 있어도 계정·정책 조회를 시작하지 않는다.
11. Copilot ZIP이 손상됐거나 현재 원본 정책보다 오래됐으면 로컬 준비 상태를 실패 폐쇄한다.
12. 로그인 계정의 조직 도메인이 허용 범위와 다르면 정책 통과 여부와 무관하게 중단한다.
13. Copilot Studio의 환경 ID를 직접 대조하지 않으면 사전 준비 상태로 승격하지 않는다.

신규 회귀 결과: 13/13 통과.

## 남은 배포 차단 조건

1. 실제 컴퓨터 초심자 교사 최소 3명이 도움 없이 역할을 선택하고 ChatGPT 첫 수업을 시작하는 관찰 시험.
2. 비공개 공유 GPT 접근 권한이 없는 교사를 위한 무복사·무붙여넣기 경로. 현재 플랫폼 권한 밖이므로 없는 기능을 자동 설치처럼 만들지 않는다.
3. 학교 IT 관리자의 사용자 지정 앱 업로드 정책 허용, `한국과학창의재단` 환경 ID 직접 대조 뒤 실제 Microsoft 365 에이전트 실행·호출·응답 모드·출처 검증.
4. Node.js와 pnpm이 없는 일반 교사용 무설치 화면. Windows 버전 보류가 해제되기 전에는 구현 완료로 표시하지 않는다.

Windows 디렉터리와 기존 dirty 작업, LICENSE, NOTICE, 저장소 공개 상태는 변경하지 않았다.
