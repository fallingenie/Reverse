# 보안 검토와 수정 보고서

기준일: 2026-08-14

이 검토는 전문 침투시험이나 법률·개인정보 감사를 대체하지 않는다.

## 수정한 항목

- GitHub Actions를 태그가 아닌 정확한 40자리 커밋 SHA로 고정했다.
- GStack 임시 보안 보고서는 Git 추적 대상에서 제외했다.
- Microsoft 365 Agents Toolkit의 설치 스크립트는 승인하지 않고 `allowBuilds: false`로 유지했다.
- 공식 CLI 추가 직후 `pnpm audit`에서 `adm-zip` 고위험 1건과 `uuid` 중간위험 1건이 발견됐다.
- pnpm workspace override로 `adm-zip 0.6.0`, `uuid 11.1.1`을 강제한 뒤 감사 결과는 알려진 취약점 0건이다.
- override 뒤 공식 Microsoft 패키지 검증 59/59와 테넌트 진단을 다시 실행해 CLI 동작을 확인했다.

## 남은 우려

- 프롬프트 주입 방어는 확률적이며 완전한 보안 경계가 아니다.
- Custom GPT의 평문 `[교사 검토]`는 인증이 아니므로 비공개 정답·교사 메모를 같은 GPT에 저장하면 안 된다.
- Microsoft 365 테넌트의 실제 앱 접근은 관리자 정책으로 차단돼 런타임 안전 동작을 아직 증명하지 못했다.
- 비공개 GPT·테넌트·계정 식별자가 과거 Git 이력이나 비공개 시험 보고서에 남을 수 있으므로 저장소 공개 전 별도 이력 감사를 해야 한다.

현재 보안 판정은 `로컬 의존성·CI 고정 통과 / 원격 런타임과 공개 이력 감사 보류`다.
