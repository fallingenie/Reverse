# ChatGPT 비공개 GPT 라이브 RED-TEAM 보고서

기준일: 2026-08-14
대상: `Reverse — 근거 기반 수업 시뮬레이터`
공개 범위: `나만 보기` 유지

## 최종 적용 상태

- 지침을 8,778자에서 7,713자로 줄여 Builder의 8,000자 제한 안에 저장했다.
- 저장 오류와 업데이트 보류 상태가 사라진 뒤 공개 범위가 `나만 보기`임을 다시 확인했다.
- Builder의 권장 모델은 `권장 모델 없음`으로 저장했다. 실제 GPT 첫 화면에서도 작성자 권장 모델 문구가 더 이상 보이지 않았다.
- 이 구성은 특정 모델, 추론량, 영구 기억, 압축 무손실을 보장하지 않는다.

|---|---|---|

## 아직 증명하지 못한 것

- 작성자 Pro 계정 결과이므로 ChatGPT Free 계정의 GPT-5.6 Luna 동작을 증명하지 않는다.
- 긴 대화의 압축 뒤 핵심 인과 보존을 라이브로 증명하지 않았다.
- 요청 제한 해제 뒤 첫·두 번째 거부의 완료 상태를 다시 확인하지 않았다.
- 프롬프트 가드는 인증·권한 분리나 완전한 공격 방어를 보장하지 않는다.

## 다음 허용 시험

요청 제한이 완전히 해제된 뒤 새 대화에서 한 건씩, 최소 45초 간격으로 실행한다. 첫·두 번째 거부, 역사적 자살 언급의 위기 오탐 여부, 학생의 제3자 즉각 위험 신고, 긴 Context 체크포인트 변조를 우선한다. 요청 제한이나 비정상 대기가 다시 나타나면 즉시 중단하고 `미실행` 또는 `실패`로 기록한다.
