# 개인정보 처리 안내

Reverse는 수업 진행 규칙과 설정 파일을 제공하는 오픈 소스 프로토타입입니다. 이 저장소 자체는 학생 계정이나 대화 내용을 수집하는 서버를 운영하지 않습니다.

ChatGPT 또는 Microsoft 365 Copilot에서 사용할 때의 대화 처리·보존·관리자 접근은 해당 서비스와 학교·기관의 계약 및 테넌트 정책을 따릅니다. 배포 기관은 사용 전에 적용 정책을 확인해야 합니다.

학생 이름, 학번, 연락처, 건강·가정 정보, 성적표 등 수업에 불필요한 개인정보를 프롬프트·PDF·지식 파일에 넣지 마세요. 학급 설정은 비식별화하고 최소한의 학년·과목·단원 정보만 사용하세요.

보안 또는 개인정보 문제는 공개 Issue에 민감정보를 올리지 말고 저장소의 `SECURITY.md` 절차를 따르세요. 기관용 비공개 신고 채널이 지정되지 않은 상태에서는 실제 학생 데이터를 사용하는 외부 베타를 진행하지 마세요.
