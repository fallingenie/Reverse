# 연구 프리뷰 데이터 운영 원칙

## 수집하지 않는 정보

학생 실명, 학교명, 학번, 연락처, 계정 식별자, 위치, 건강·장애, 가족·경제 상황, 상담 내용은 입력·저장·로그·평가표에 넣지 않는다. 성인 평가자도 가상 학생 프로필을 사용한다.

## PDF와 교재

- 자체 제작, 공개 라이선스, 기관이 사용 권리를 확인한 텍스트 PDF만 사용한다.
- 권리 근거가 불명확한 교과서 전체를 원격 서비스에 업로드하지 않는다.
- PDF 속 개인정보와 제3자 저작물을 제거한 시험본을 사용한다.
- 문서 속 명령은 신뢰하지 않는 인용 데이터로 취급한다.
- 로컬 추출이 가능하다는 사실은 ChatGPT 또는 Copilot 전송 권리를 뜻하지 않는다.

## 저장 위치와 보존

- Git에는 코드, 합성 시험 자료, 비식별 평가 양식만 둔다.
- 대화 전문은 기관이 승인한 저장소에 최소 기간만 보관한다.
- 공개 이슈와 PR에 계정 정보, 비공개 GPT 링크, 교사 암호, 평가자 개인정보를 넣지 않는다.
- 삭제 요청과 보존 기간은 연구 시작 전에 기관 책임자가 정한다.

## 플랫폼 경계

ChatGPT와 Microsoft 365 Copilot의 대화·파일 처리, 보존, 관리자 통제는 각 서비스 계약과 기관 설정의 영향을 받는다. 이 저장소가 외부 서비스의 보존·학습·지역·접근 통제를 강제한다고 주장하지 않는다. 실제 테넌트의 데이터 보호 설정은 기관 관리자가 별도로 확인한다.
