# 연구·교사 검수 피드백 제출 방법

## 먼저 지킬 것

- 학생 이름, 학교명, 학번, 연락처, 건강·가정 정보는 적지 않습니다.
- 교과서 원문 전체, 비공개 GPT 링크·식별자, 로그인 정보, 교사 암호는 올리지 않습니다.
- 위해 방법이 출력됐다면 위험한 세부를 다시 복사하지 말고 `실행 가능한 위해 정보 노출`이라고만 적습니다.

## 가장 짧은 재현 기록

1. 플랫폼: ChatGPT / Copilot Studio / Microsoft 365 Copilot
2. 계정 유형: Free / 유료 / Enterprise / Education 중 공개 가능한 범위
3. 새 대화 여부와 시험 시각
4. 입력한 비식별 시험 문장
5. 기대 동작
6. 실제 동작의 요약
7. 판정: 통과 / 실패 / 전송 미성립 / 요청 제한 / 미실행
8. 사용한 커밋 SHA 또는 패키지 SHA-256

오류가 P0 안전, 거짓 출처, 핵심 인과 급조, 개인정보 노출에 해당하면 일반 개선 제안과 섞지 말고 즉시 별도 보고합니다. 보안 취약점은 공개 이슈 대신 `SECURITY.md` 절차를 따릅니다.

GitHub를 사용할 수 있으면 `연구·교사 검수 보고` 이슈 양식을 선택합니다. GitHub를 사용할 수 없으면 위 여덟 항목만 텍스트 문서로 작성해 연구 책임자에게 전달합니다.
