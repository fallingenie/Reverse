## 수집·공개 경계

Copilot Studio의 대화 영역은 가상 스크롤을 사용하므로 한 시점의 복사나 DOM 조회에는 전체 대화가 나타나지 않았다. 대화 영역의 처음부터 끝까지 약 350px 간격으로 이동하면서 메시지의 화면상 절대 위치를 대조했다. 그 결과 사용자 24개와 Agent 25개가 번갈아 나타나는 순서를 재구성했고, 모든 `Reasoned through your request` 카드가 펼쳐진 상태임을 확인했다.

이 문서에는 Preview에 실제 표시된 짧은 reasoning 요약, Skill 호출명, 검색 질의, 출처 제목·URL, 최종 응답을 포함한다. 화면에 표시되지 않은 비공개 내부 추론은 복원하거나 꾸며 쓰지 않는다. 검색 도구가 노출한 제3자 문서의 장문 본문은 전문을 재배포하지 않고 제목·URL·직접지지 범위만 남긴다. 내부 스니펫 경로를 읽으라는 도구 지시문은 보안 경계 결함의 직접 증거이므로 그대로 기록한다.

## 과목별 앵커 계약

이 결함은 과학에만 한정하지 않는다.

- 국어: 읽기, 표현, 문체, 근거 있는 해석이 사건 해결의 실제 행동이어야 한다.
- 수학: 수량, 관계, 표현, 추론, 검산이 단서와 피드백을 움직여야 한다.
- 사회·역사: 자료, 시점, 제도, 인과, 이해관계를 비교해야 한다.
- 과학: 관찰, 예측, 측정, 변인, 모형, 인과를 사용해야 한다.
- 도덕·윤리: 가치 충돌, 행위자, 원칙, 결과, 반론을 비교해야 한다.

다른 분야의 질문은 한 번의 짧은 보조 답변으로 처리할 수 있다. 사용자가 과목 변경을 명시하지 않은 경우 다음 행동과 피드백은 선택 과목으로 돌아온다. 배경 분야가 해결 방법을 대신하면 새 장면을 이어 쓰지 않고 `교과 연결 재정렬` 뒤 학습 목표와 행동을 수정한다.

>
> 근거로부터 추론
> 수동적으로 문제를 푸는 수업보다 자유 행동에 세계가 반응하는 이야기를 기대하는 것으로 보입니다.
> 분위기만 그럴듯한 이야기보다 인과관계와 현실성이 유지되는 이야기에 더 몰입하는 경향이 있습니다.

## 잔여 검증과 라이브 판정

이 보고서 생성 시점의 완료 조건은 다음과 같다.

1. ChatGPT·Copilot 지침이 각각 8,000자 미만이고 UTF-8-SIG여야 한다.
2. 학생 Skill과 Prompt는 UTF-8-SIG, JSON·MJS fixture/test는 UTF-8 무BOM이어야 한다.
3. 표적 회귀, 전체 `pnpm test`, `pnpm run validate`, 문자 무결성 검사가 모두 통과해야 한다.
4. 학생용 Skill ZIP을 재생성하고 파일 수·SHA-256·manifest seal을 다시 기록해야 한다.
5. Copilot Studio의 Instructions와 Skill을 새 산출물로 저장한 뒤 새 Preview 채팅에서 학년·과목 이탈·프로파일·화면 복사 canary를 순차 실행해야 한다.
6. 로컬·라이브 검증이 모두 끝나기 전에는 게시·GitHub Pages·Vercel 배포 완료를 주장하지 않는다.

## 보존한 장점

- 사용자가 지적한 폐교 장면의 개연성 오류를 인정하고 시간·장소·보호자 조건을 국소 수정했다.
- 전기 주변 물 사용, 석면 장갑, 정체불명 와이어 절단·당기기를 안전하게 차단했다.
- 석면의 내열성과 섬유 노출 위해를 구분해 사용자의 과학적 의도를 뒤늦게나마 교정했다.
- 동시에 움직이는 두 장치에서 상관관계와 인과 방향을 구분하는 과학 탐구 장면으로 복귀했다.
- 공무상 재해·순직과 부실공사를 자동 확정하지 않고 심사·추가 자료 필요성을 밝혔다.

이 장점은 유지하되, 안전·법률 보조 설명이 선택 과목의 학습 방법을 대체하지 않도록 런타임 앵커를 강제한다.
