# 설계 기록

## 목표

긴 프롬프트 기반 서사 시뮬레이션에서 관찰된 모듈성, 상태 연속성, 인과적 반응성을 교육에 맞게 재구성한다. 원 프로젝트의 고유 세계관과 명칭을 복제하지 않고, 공개된 v4 구조와 사용자가 제공한 후속 사용 경험에서 행동 수준의 요구만 추출한다.

## 유지한 행동 원리

| 관찰한 원리 | 교육용 구현 |
|---|---|
| 기능별 책임 분리 | 온보딩, 근거, 수업 턴, 기억, 안전, 교사 모드를 별도 파일로 분리 |
| 선택 뒤 상태 변화 | 턴마다 학생 선택, 지역적 결과, 기억 델타를 순서대로 기록 |
| 장면의 인과 연속성 | 시간, 장소, 물자, 제도, 정보 접근 제약을 `current_state`에 유지 |
| 장기 대화 상태 | JSON 세션과 원본 턴을 유일한 상태 근거로 사용 |
| 사용자 주도 선택 | 번호 선택과 직접 입력을 모두 허용 |

## 제거한 요소

- 초자연 법칙, 판타지 능력, 운명적 세계관
- 전투·수집·등급 상승 중심의 게임화
- 출처 없이 정밀해 보이는 수치와 학술 용어
- 모델 내부 추론을 그대로 노출하는 형식
- 특정 작품의 고유 명칭과 상태 객체
- 학생 한 명의 행동이 즉시 세계사를 결정하는 과장

## 추가한 교육 기능

### 시작 게이트

학년, 과목, 관심사를 먼저 받고 다섯 시나리오를 제안한다. 선택 뒤 `[시작]`을 받기 전에는 장면을 생성하지 않는다. 이 상태 기계는 학생의 요구를 추측하거나 수업이 성급하게 시작되는 문제를 막는다.

### 근거 상태

모든 핵심 주장은 `VERIFIED`, `DERIVED`, `SCENARIO`, `UNKNOWN`으로 구분한다. 반사실 가정은 실제 사실의 빈칸을 채우는 정보가 아니라 탐구 조건이다.

### 압축 내성 기억

컨텍스트 압축이 무엇을 남길지 모델의 임의 판단에 맡기지 않는다. 핵심 사실, 부정 사실, 학생 선택, 결과, 교정, 출처, 열린 질문을 구조화하고 ID로 비교한다. 압축은 원본을 덮어쓰지 않으며 입력 해시와 순번을 기록한다.

### 학년 밴드

초3~4, 초5~6, 중1~3, 고1~2의 분량, 개념 수, 자료 비교 수준을 별도로 정한다. 같은 주제라도 사실의 핵심을 바꾸지 않고 언어와 과제 복잡도만 조정한다.

### 교사 모드

학생용 몰입 장면과 교사용 근거·평가 메모를 분리한다. 평가는 결론의 일치보다 근거 사용, 불확실성 표현, 관점 비교, 자기 교정을 본다.

## 기억 압축 불변식

압축 전후에 다음 ID 집합이 같아야 한다.

1. `must_keep`인 근거 레코드
2. `must_keep`인 canon
3. 모든 부정 사실
4. 모든 교정
5. 열린 질문
6. 보존 대상으로 지정된 에피소드

불변식이 깨지면 압축본을 사용하지 않고 오류를 보고한다.

## 첫 예시의 인과 경계

분기점은 “미국의 핵무기 개발 실패” 하나다. 분기 이전의 포츠담 선언 준비와 당시 전쟁 상황은 실제 역사 자료로 다룬다. 소련 참전을 유지하는 것은 최소 변경을 위한 별도 `SCENARIO`이며 실제 역사에서 확인되는 사건과 구분한다. 일본의 항복 날짜, 조선의 해방 날짜, 점령과 분단의 경로는 `UNKNOWN`으로 남긴다.

## 검증 전략

- UTF-8 전체 파일 검사
- 필수 문서와 Apache 2.0 고지 검사
- Skill 고유 명칭과 frontmatter 검사
- 온보딩 세 질문, 다섯 카드, `[시작]` 게이트 검사
- JSON Schema 엄격 검증
- 출처와 근거 ID 참조 무결성 검사
- 기억 압축 전후 보존 ID 검사
- 실제 CLI 압축 실행
