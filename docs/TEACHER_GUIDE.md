# Reverse 교사용 가이드

이 가이드는 컴퓨터 설치나 명령어에 익숙하지 않은 교사를 위한 안내서입니다. 수업을 체험하거나 학생과 사용할 때는 프로그램을 내려받을 필요가 없습니다. 아래 웹 주소를 열고 화면의 안내를 따르면 됩니다.

## 3분 안에 시작하기

1. [Vercel의 Reverse 수업 화면](https://reverse-education-beta.vercel.app/)을 엽니다.
2. Microsoft 로그인 화면이 나타나면 학교나 기관에서 허용한 업무·교육용 계정으로 로그인합니다.
3. 에이전트가 학교급을 물으면 `초등학교`, `중학교`, `고등학교` 중 하나로 답합니다.
4. 이어서 학년, 과목, 현재 공부 중인 단원을 입력합니다.
5. 학생에게 제시하기 전에 교사가 같은 조건으로 한 번 체험하고 사실성, 학년 적합성, 안전성을 확인합니다.

Git, Node.js, pnpm을 설치하거나 `git clone` 명령을 실행할 필요는 없습니다. 그런 도구는 소스 코드를 수정하거나 자체 배포를 맡은 개발자와 학교 정보 담당자에게만 필요합니다.

## 어느 웹 주소를 사용하나요?

| 화면 | 언제 사용하나요? | 알아둘 점 |
|---|---|---|
| [Vercel](https://reverse-education-beta.vercel.app/) | 일반 체험과 교사 검수 기능을 확인할 때 | 교사 내보내기는 서버 설정이 완료된 배포에서만 열립니다. |
| [GitHub Pages](https://fallingenie.github.io/Reverse/) | Vercel에 접속할 수 없거나 정적 화면을 확인할 때 | 서버 기능이 없으므로 교사 키 확인과 Markdown 내보내기를 사용할 수 없습니다. |
| [GitHub 저장소](https://github.com/fallingenie/Reverse) | 문서, 라이선스, 변경 이력, 소스 코드를 확인할 때 | 수업을 체험하기 위해 저장소를 내려받을 필요는 없습니다. |

두 웹 화면에 삽입된 Copilot 대화는 Microsoft가 제공하는 별도 서비스입니다. Reverse가 Microsoft 계정 권한, 조직의 공유 정책, 로그인 상태를 바꿀 수는 없습니다.

## 로그인 또는 대화 화면이 열리지 않을 때

다음 순서로 확인합니다.

1. 개인용 Microsoft 계정이 아니라 학교나 기관에서 허용한 업무·교육용 계정으로 로그인했는지 확인합니다.
2. 브라우저의 추적 방지나 제3자 쿠키 차단 때문에 삽입 화면이 막혔다면, 화면에 있는 `새 창에서 열기`를 누릅니다.
3. `접근할 수 없음`, `권한이 없음` 또는 비슷한 메시지가 나오면 같은 동작을 반복하지 말고 학교 정보 담당자에게 화면을 보여 줍니다.
4. 학교 정보 담당자는 에이전트 게시 상태, 공유 대상, Copilot Studio 환경, 조직의 사용자 지정 에이전트 정책을 확인합니다.

패키지 형식 검사를 통과했다는 사실만으로 모든 학교 계정에서 실행되는 것은 아닙니다. 현재 공개 웹 화면은 게시된 한 에이전트에 연결되어 있습니다. 다른 기관이 자체 Copilot Studio 환경으로 가져올 때는 그 기관의 관리자 승인과 실제 계정 시험이 다시 필요합니다.

## 수업 전에 교사가 확인할 것

### 사실과 출처

- 역사·과학·사회 사실에는 해당 주장을 직접 뒷받침하는 출처가 있는지 확인합니다.
- 검색 결과의 짧은 요약만 보고 사실로 확정하지 않습니다.
- 실제 사실, 사실에서 제한적으로 이끌어 낸 해석, 수업을 위한 설정, 아직 확인하지 못한 내용을 구분합니다.
- 과학 법칙이나 연표가 충돌하면 이야기를 계속 진행하기보다 충돌한 전제를 먼저 고칩니다.
- 핵심 전제가 무너졌다면 부분 수정으로 숨기지 말고 학생에게 설명한 뒤 다시 시작할지 결정합니다.

### 수업 수준

- 학생이 속한 학교급을 먼저 확인하고 그다음 학년을 확인합니다.
- 학생이 입력한 단원을 수업의 중심 주제로 사용합니다.
- 단원까지 정해졌다면 관련 없는 범용 관심사를 다시 묻지 않는지 확인합니다.
- 정답을 먼저 알려 주는 문제 풀이가 아니라 학생의 선택에 따라 상황이 이어지는 수업인지 확인합니다.

### 안전

- 자신이나 타인에게 위해를 줄 수 있는 약물 용량, 무기 제작, 위험 실험 절차는 교사에게도 제공하지 않습니다.
- 위험 질문은 역사적 맥락, 윤리, 법, 공중보건, 안전한 모형이나 비실행형 분석으로 바꿉니다.
- 즉각적인 자해·타해 위험이 의심되면 수업을 중단하고 학교의 공식 보호 절차와 지역 응급 지원을 이용합니다.

## 학생 정보를 넣지 마세요

다음 정보는 대화, PDF, 지식 파일, 교사 기록, 내보낸 Markdown에 넣지 않습니다.

- 실명, 학교명, 학번, 연락처, 계정 식별자
- 주소, 위치, 건강·장애, 진단명, 상담 내용
- 가족·경제 상황, 성적표, 징계 기록
- 실제 학생을 알아볼 수 있는 자유 서술

학급과 학생을 구분해야 한다면 수업 안에서만 쓰는 가명 ID를 사용합니다. 예를 들어 `RVS-A2B3C4`처럼 원래 신원을 짐작할 수 없는 값을 사용합니다.

ChatGPT나 Microsoft 365 Copilot에 입력한 대화와 파일의 보존 방식은 각 서비스와 학교·기관의 계약 및 설정을 따릅니다. Reverse 웹 화면이 외부 서비스의 보존 기간이나 관리자 접근을 강제로 바꾸지는 못합니다.

## 교사가 학생 활동을 기록할 때

교사 기록은 학생을 자동 평가하거나 성격·능력을 진단하는 기능이 아닙니다. 다음 원칙을 지킵니다.

1. 학생이 실제로 선택하거나 말한 내용만 기록합니다.
2. 에이전트가 먼저 제안한 행동을 학생의 성취로 기록하지 않습니다.
3. 한 번의 선택을 흥미, 학업 능력, 오개념의 확정 근거로 사용하지 않습니다.
4. `활동 기록`, `잠정 관찰`, `미평가`를 정식 평가와 구분합니다.
5. 건강, 장애, 가정환경, 상담, 학대 의심 같은 민감한 내용을 교사 메모에 넣지 않습니다.

보호가 필요한 상황은 웹 기록으로 관리하지 말고 학교의 공식 보호 절차를 따릅니다.

## Markdown 내보내기 상태

현재 공개 수업 화면에는 교사 프로필 편집이나 Markdown 내보내기 버튼이 없습니다. 관련 서버 모듈이 있어도 공개 화면에 연결하고 회귀 검증하기 전에는 사용할 수 있는 기능으로 안내하지 않습니다.

향후 내보내기가 활성화되면 교사가 특정 키를 입력했을 때만 열리며, 서버 설정이 완료된 Vercel 배포에서만 사용할 수 있습니다. GitHub Pages에서는 사용할 수 없습니다.

1. `교사 검수` 화면을 엽니다.
2. 내보내기가 필요한 시점에만 교사 키를 입력합니다.
3. 가명 학생 ID와 포함할 기록을 확인합니다.
4. `Markdown 미리보기 만들기`를 누릅니다.
5. 개인정보, 민감정보, 근거 없는 평가가 없는지 읽어 봅니다.
6. 필요한 경우에만 UTF-8-SIG Markdown 파일로 저장합니다.
7. 작업을 마치면 교사 화면을 잠그고 공유 기기의 탭을 닫습니다.

교사 키는 안전 규칙을 해제하는 암호가 아닙니다. 교사 신원을 증명하는 개인 계정도 아닙니다. 현재 구현 후보의 키는 내보내기 기능에만 접근하는 공유 운영 키이며, 인증에 성공한 세션은 15분 뒤 만료되도록 설계되어 있습니다.

자세한 설정과 운영 한계는 [교사용 내보내기 보안 안내](TEACHER_EXPORT_SECURITY.md)를 확인하세요.

## 학교 정보 담당자에게 전달할 내용

교사가 로그인이나 권한 문제를 해결할 수 없다면 다음 네 가지만 전달하면 됩니다.

- 사용한 웹 주소
- 오류가 발생한 날짜와 시각
- 개인정보를 가린 오류 화면
- 사용한 계정의 종류가 업무·교육용인지 여부

암호, 교사 키, 세션 값, 학생 대화 전문, 비공개 GPT 링크는 이메일이나 공개 이슈에 보내지 않습니다. 비공개 신고 경로가 정해지지 않았다면 실제 학생 데이터를 사용한 외부 시험을 시작하지 않습니다.
