# 베타 공개 준비 판정

기준일: 2026-08-14

## 현재 판정

| 대상 | 판정 | 허용 범위 |
|---|---|---|
| 개발팀 내부 시험 | 진행 가능 | 가상 학생 계정과 비식별 테스트 자료만 사용한다. |
| 교수·박사·교사 5~12명의 초대형 연구 프리뷰 | ChatGPT 한정 조건부 | 아래 필수 조건과 기관 검토를 충족한 정확한 커밋·비공개 초대만 사용한다. Microsoft 365 경로는 테넌트 정책 차단 해소 전 제외한다. 제품 효과가 입증됐다고 표현하지 않는다. |
| 연구재단 공식 베타 모집 | 보류 | 목표 플랫폼의 실제 계정 검증, 외부 교과 전문가 감사, 연구·개인정보 검토가 끝나지 않았다. |
| 학생 또는 미성년자 학급 시험 | 진행 금지 | 기관의 연구윤리·보호자 동의·개인정보·접근성·교사 감독 절차가 없다. |
| GitHub 공개 저장소 전환 | 보류 | 현재 파일에서는 비공개 GPT 식별자를 제거했지만 기존 Git 이력의 QA 기록에는 남아 있다. 공개 전 이력 정리 또는 식별자가 다른 공개용 저장소가 필요하다. |
| Windows 독립 실행본 | 현 단계 보류 | 소스 무결성 시험만 유지한다. 실행 파일을 현재 평가판에 포함하거나 완성된 통합 Add-on으로 설명하지 않는다. |

## 초대형 연구 프리뷰의 필수 조건

1. PR의 기준 커밋, 시험 결과, export seal을 현재 값으로 갱신한다.
2. 현 단계 활성 대상인 ChatGPT·Copilot CI가 정확한 커밋에서 통과한다. Windows 작업은 보류 해제 전 CI에 포함하지 않는다.
3. 로컬 지침과 실제 비공개 Custom GPT 설정이 동일하다는 내용을 사람이 대조한다.
4. 실제 ChatGPT Free 참가 계정에서 학교급부터 시작하는 온보딩, 다섯 시나리오, 별도 `[시작]` 게이트를 시험한다.
5. Microsoft 365 앱 manifest, 필수 아이콘, 선언형 에이전트 정의를 포함한 업로드용 ZIP 패키지를 만들고 현재 Microsoft 검증 도구를 통과시킨다.
6. Microsoft 365 경로를 프리뷰에 포함하려면 실제 Enterprise/Education 테넌트에서 완성 패키지의 실행 권한, 기본 응답 모드, 사용자 변경, `@mention` 예외를 확인한다. 통과 전에는 초대문·평가표에서 Microsoft 365 경로를 명시적으로 제외한다.
7. `docs/RESEARCH_EVALUATION_PROTOCOL.md`의 P0, 과학, 연표, 출처, 기억, 학년 적합성 시험을 실행한다.
8. 참가자는 성인 전문가로 제한하고 학생 개인정보와 저작권이 불명확한 교과서 원문을 사용하지 않는다.
9. 알려진 한계, 실패 사례, 수정 이력을 평가자에게 먼저 제공한다.
10. 교사별 파생 GPT가 필요하면 Business·Enterprise·Edu 작업공간의 생성·공유 권한을 실제 관리자가 확인한다. 개인 Free·Go·Plus·Pro 계정에서 새 GPT를 만들 수 있다고 안내하지 않는다.

공개 GitHub 배포는 위 초대형 프리뷰와 별도다. 기존 이력에 남은 비공개 GPT·대화 식별자를 정리하고, 공개할 정확한 커밋을 새로 검사하기 전에는 저장소를 공개하지 않는다.

## 즉시 중단 조건

- 위험 절차가 여러 턴을 거쳐 실행 가능한 형태로 제공된다.
- 근거가 없는 현실 주장을 사실로 표시하거나 존재하지 않는 출처를 만든다.
- 압축이나 대화 재개 뒤 핵심 인과를 급조하고 교정 사실을 숨긴다.
- 학교급·학년을 추측하거나 `[시작]` 이전에 수업 장면을 진행한다.
- 학생용 화면에 내부 실행 프로필, 권한 코드, 교사용 정답·평가 기록을 노출한다.
- 플랫폼 또는 모델 능력을 공개 문서보다 강하게 보장한다.
- 평가 자료에 학생 실명, 학교명, 연락처, 건강·가정 정보가 들어간다.

## 외부 설명에 사용할 수 있는 표현

`근거와 가정을 구분하고 오류 교정을 추적하도록 설계된 연구용 프로토타입`이라고 설명할 수 있다. `과학적으로 검증된 교육 효과`, `환각 방지 보장`, `특정 모델 강제`, `영구 기억`, `안전 완전 보장`, `학생 배포 준비 완료`라고 설명하면 안 된다.
