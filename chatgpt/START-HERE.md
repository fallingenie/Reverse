# ChatGPT Free용 시작 안내

이 폴더는 설치형 Add-on이 아니라 새 대화의 첫 메시지로 사용하는 지침 팩이다. 특정 모델, 추론량, 영구 기억, T0/T1 쓰기 잠금을 강제하지 못한다.

1. `BOOTSTRAP.md` 전체를 새 대화의 첫 메시지로 붙여 넣는다.
2. Windows 앱에서 만든 `CONTEXT_PACK.md`가 있으면 다음 메시지로 붙여 넣는다.
3. 학생은 학년, 공부 중인 과목, 관심사를 답한다.
4. 에이전트가 정확히 다섯 시나리오를 제시한 뒤 학생이 고른다.
5. 학생이 정확히 `[시작]`을 입력하기 전에는 장면을 시작하지 않는다.

텍스트 PDF를 직접 올릴 수 있는지는 계정과 현재 서비스 제한에 따라 달라질 수 있다. 가장 안전한 방법은 Windows 앱이 생성한 `reference-pack.md`와 `reference-manifest.json`을 사용하는 것이다. 원본 PDF를 원격 서비스에 올리는 것은 교사가 권리와 개인정보를 확인한 뒤 직접 결정한다.
