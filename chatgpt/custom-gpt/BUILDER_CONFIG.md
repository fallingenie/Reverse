# Reverse Custom GPT 구성표

## 표시 정보

- 이름: `Reverse — 근거 기반 수업 시뮬레이터`
- 설명: `초3~고2 학생이 사실·근거·가정을 구분하며 선택형 시나리오로 배우는 비공개 수업 테스트 GPT입니다.`
- 공개 범위: `나만 보기`
- 권장 모델: `권장 모델 없음` (특정 모델은 권장일 뿐 강제가 아니며 추론량을 보장하지 않는다)

## 대화 스타터

1. `초등학교 수업을 시작할게요.`
2. `중학교 수업을 시작할게요.`
3. `고등학교 수업을 시작할게요.`
4. `방금 응답의 사실성과 학년 적합성을 공개 가능한 범위에서 점검해 주세요.`

## 기능

- 웹 검색: 켬
- 이미지 생성: 끔
- 코드 인터프리터 및 데이터 분석: 켬
- 앱: 사용하지 않음
- 작업: 사용하지 않음

## Builder 입력

- 지침: `INSTRUCTIONS.md`의 본문 전체
- 지식: `KNOWLEDGE_REFERENCE.md`
- 선택 지식: 교사가 대괄호 안을 수정한 `../CLASSROOM_SETTINGS.example.md`; 학생 개인정보, 숨은 정답, 비공개 루브릭·교사 메모, 인증정보가 없는지 먼저 확인

처음 만드는 교사는 `../TEACHER-QUICK-START.md`부터 읽는다. 공유받은 GPT를 사용하는 권한과 GPT를 편집하는 권한은 다르며, 편집 권한이 없으면 일반 대화에서 `BOOTSTRAP.md`와 학급 설정표를 붙여 넣는 방식을 사용한다.

## 보장 경계

Custom GPT는 프롬프트 가드다. 모델·추론량·컨텍스트 압축·영구 기억을 강제하지 못하며 Windows Host의 T0/T1 쓰기 잠금과 해시 원장을 실행하지 않는다. 이미지 기능을 꺼도 제품 화면의 전역 이미지 진입점이 보일 수 있으므로 구성 토글을 제품 전체 UI를 제거하는 권한으로 취급하지 않는다.

날짜별 라이브 시험, 응답 시간, 미실행·실패 사례는 이 구성표에서 누적하지 않고 `../../docs/reports/CHATGPT_LIVE_RED_TEAM_2026-08-14.md`에 기록한다.
