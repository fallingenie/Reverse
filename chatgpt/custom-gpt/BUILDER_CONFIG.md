# Reverse Custom GPT 구성표

## 표시 정보

- 이름: `Reverse — 근거 기반 수업 시뮬레이터`
- 설명: `초3~고2 학생이 사실·근거·가정을 구분하며 선택형 시나리오로 배우는 비공개 수업 테스트 GPT입니다.`
- 공개 범위: `나만 보기`
- 권장 모델: `Thinking 5.6` (권장일 뿐 강제가 아니며 대체 모델이 사용될 수 있음)

## 대화 스타터

1. `수업을 시작하고 싶어요.`
2. `교과서 PDF를 참고자료로 사용하고 싶어요.`
3. `제가 원하는 역사적 분기점을 제안할게요.`
4. `[교사 검토] 모드에서 수업 응답의 사실성과 학년 적합성을 점검해 주세요.`

## 기능

- 웹 검색: 켬
- 이미지 생성: 끔
- 코드 인터프리터 및 데이터 분석: 켬
- 앱: 사용하지 않음
- 작업: 사용하지 않음

## Builder 입력

- 지침: `INSTRUCTIONS.md`의 본문 전체
- 지식: `KNOWLEDGE_REFERENCE.md`

## 보장 경계

Custom GPT는 프롬프트 가드다. 모델·추론량·컨텍스트 압축·영구 기억을 강제하지 못하며 Windows Host의 T0/T1 write lock과 hash-chain ledger를 실행하지 않는다. GPT Builder의 권장 모델은 사용자가 선택할 수 없는 경우 대체될 수 있고, 사용자가 다른 모델로 전환할 수도 있다.

2026-08-13 비공개 테스트에서 Builder의 선택값은 `Thinking 5.6`이었지만 실제 GPT 화면은 `GPT-5.6 Sol` 권장으로 표시했다. 둘의 내부 대응을 추정하지 않는다. 또한 Builder에서 이미지 생성을 꺼도 실제 GPT 화면에 전역 `이미지 만들기` 진입점이 노출됐다. 구성 토글은 GPT가 자발적으로 사용할 기능을 제한하지만 제품 전체 UI를 제거하는 권한으로 취급하지 않는다.
