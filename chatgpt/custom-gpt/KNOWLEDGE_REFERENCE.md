# Reverse 용어·판정 참고표

이 문서는 행동 지침이 아니라 수업 중 사용하는 상태와 판정 용어의 참조표다. 실제 사실을 담은 교과서나 사료가 아니며, 각 수업의 사실 주장은 별도로 조사해야 한다.

## 사실 상태

| 상태 | 의미 | 허용되는 표현 |
|---|---|---|
| VERIFIED | 열린 원문이 직접 지지함 | 확인됨, 원문에 따르면 |
| DERIVED | 확인된 자료에서 제한적으로 도출함 | 자료를 종합하면, 단 이 범위에서 |
| SCENARIO | 반사실 가정 또는 수업 설정 | 이 수업에서는 ~라고 가정 |
| UNKNOWN | 근거 부족 또는 아직 미정 | 현재 알 수 없음, 아직 정하지 않음 |
| NOT_LOADED | 외부 기록에 있을 수 있으나 현재 없음 | 기록을 다시 불러와야 함 |
| CONFLICTED | 신뢰 가능한 자료가 충돌함 | 자료 간 차이가 있어 확정하지 않음 |

## Canon 내구성

| 층 | 예 | Custom GPT 권한 |
|---|---|---|
| T0 | 실제 역사 기준, 분기점, 핵심 수업 전제 | 읽기·변경 제안만 가능 |
| T1 | 장기 인물, 기관, 질병 원인, 핵심 인과 | 읽기·변경 제안만 가능 |
| T2 | 현재 에피소드의 물자·관계·목표 | 대화 중 후보 갱신 가능 |
| T3 | 현재 시간·장소·즉시 행동 | 대화 중 후보 갱신 가능 |
| T4 | 문체·분위기·일회성 묘사 | 필요하면 버릴 수 있음 |

`caused_by`로 연결된 원인이 누락되면 현재 결과를 설명할 새 원인을 만들지 않는다. 핵심 사실을 변경하려면 이전 값, 제안 값, 근거, 영향 범위가 포함된 `CANON_PROPOSAL`이 필요하다.

## 출처 품질 참고

- A: 직접 관련된 법령·공식 통계·원자료·1차 사료·동료평가 원문처럼 책임 주체와 방법을 확인할 수 있는 자료
- B: A 자료를 충실히 종합한 공신력 있는 기관·대학·전문학회 자료
- C: 출처가 표시된 일반 해설이나 교육 자료
- D: 출처 불명 요약, 검색 스니펫, 생성형 답변, 홍보성 페이지

도메인, 기관명, 피인용 수는 보조 신호일 뿐 자동 합격 조건이 아니다. 검색 결과의 짧은 요약은 원문을 대신하지 않는다. 동일 자료를 재인용한 여러 페이지는 독립 출처 여러 개로 세지 않는다.

## 교정 영향도

- LOCAL_PATCH: 한 문장, 수치, 명칭처럼 국소 수정으로 인과망이 유지됨
- TRACK_REBASE: 여러 상태나 장면을 다시 계산해야 하지만 핵심 분기점은 유지됨
- RESTART_RECOMMENDED: 분기점, 연표, 핵심 인물 원인, 과학 법칙이 무너져 기존 진행의 상당 부분을 신뢰할 수 없음

## 학년별 인지 부하

- 초3~4: 구체적 행동과 관찰 중심, 한 번에 새 개념 2개 이하
- 초5~6: 원인과 결과 1~2단계, 짧은 사료 비교
- 중1~3: 상반 자료, 제도, 이해관계 비교
- 고1~2: 구조적 원인, 자료 한계, 반론과 대안 설명

## 실행 보장 범위

Custom GPT는 지침 준수를 시도하지만 모델이나 추론량을 고정하지 못한다. 채팅 밖의 영구 원장, 암호 기반 교사 권한, 학급별 로컬 학습, 검증된 T0/T1 commit은 Windows Host의 기능이다. 이 지식 파일이 첨부됐다는 사실만으로 그 기능이 활성화되지는 않는다.
