# 교사용 빠른 시작

## 가장 쉬운 사용법

### 공유 GPT가 있는 경우

1. 학생에게 공유하기 전에 교사 계정으로 링크를 엽니다.
2. 학교급, 학년, 과목·단원, 관심사를 차례로 입력합니다.
3. 시나리오를 고르고 `[시작]`을 입력합니다.
4. 과학·역사 사실과 타임라인을 일부러 의심하는 질문을 던집니다.
5. 답이 이상하면 `[교사 검토]`라고 입력하고 사실성, 출처, 학년 적합성, 안전성을 각각 확인합니다. 이 문구는 로그인이나 교사 인증이 아니므로 학생에게 숨길 정답 자료를 같은 GPT에 넣지 않습니다.

공유받은 GPT를 사용하는 것만으로는 그 GPT의 지침을 편집할 수 없습니다. 자신의 비공개 사본을 만들려면 조직의 GPT 생성·편집 권한이 필요합니다.

### 일반 ChatGPT 대화에서 쓰는 경우

1. `BOOTSTRAP.md` 전체를 새 대화의 첫 메시지로 붙여 넣습니다.
2. `CLASSROOM_SETTINGS.example.md`를 복사해 대괄호 안만 고칩니다.
3. 고친 학급 설정을 두 번째 메시지로 붙여 넣습니다.
4. 에이전트가 적용한 항목과 적용하지 못한 항목을 설명하는지 확인합니다.
5. 수업 기록을 이어 가려면 교사가 검토한 `CONTEXT_PACK.md`를 다음 새 대화에 다시 제공합니다.

이 방법의 학급 설정은 해당 대화에만 적용됩니다. 새 대화에 자동으로 남는다고 가정하지 마세요.

## 교사가 편집해도 되는 것

- 학년과 과목·단원
- 수업 목표와 관심사 예시
- 문장 길이와 용어 설명 방식
- 한 선택지에 담을 행동 수
- 학급 전체에 적용할 민감 주제와 안전한 대체 활동
- 교사가 권리를 확인한 참고 자료의 제목과 범위

## 직접 완화하면 안 되는 것

- 자신 또는 타인에게 위해를 줄 수 있는 실행 방법 제한
- 사실·추론·수업 가정·확인 필요의 구분
- 웹 원문 확인과 출처 한계 표시
- 학교급 다음 학년을 묻는 순서
- 다섯 시나리오와 `[시작]` 게이트
- 핵심 설정을 조용히 바꾸지 않는 규칙
- 학생 개인정보를 저장하지 않는 규칙

## 수업 전 10분 확인표

- [ ] 학생 이름·학번·연락처·건강·가정 정보를 넣지 않았다.
- [ ] 학교급과 학년을 따로 묻는다.
- [ ] 실제 사실과 수업을 위한 가정을 구분한다.
- [ ] 출처가 주장을 직접 뒷받침하는지 확인한다.
- [ ] 과학 법칙과 타임라인 충돌 질문에 억지로 답하지 않는다.
- [ ] 위험한 제작법·용량·최적화 질문을 안전한 학습 방향으로 전환한다.
- [ ] 오류를 인정하고 부분 교정 또는 재시작 선택지를 제시한다.

## 지속형 학급 포크가 필요한 경우

저장소의 `teacher-grounded-testbed`는 학급별 규칙을 로컬에 저장하고 학생용 포크를 만드는 개발·평가용 도구입니다. 현재는 Node.js와 명령줄 사용이 필요하므로 초심자용 무설치 기능으로 소개하지 않습니다. `pnpm teacher -- --help`에서 지원 명령과 예시를 확인할 수 있습니다.
