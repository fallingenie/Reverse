# 교사 로컬 학습과 학급 포크

교사가 학생 경험을 시험하고 설치별 로컬 오버레이를 학습시킨 뒤, 검증된 항목만 포함한 학생 전용 학급 포크를 만든다. 기반 모델을 재훈련한다고 표현하지 말고 검색·주입되는 지속형 로컬 학습이라고 설명한다.

## 필수 자료

시작할 때 `references/teacher-protocol.md`를 읽는다. 모든 로컬 저장 작업은 `scripts/teacher-store.mjs`로 수행한다. 임의의 파일 쓰기나 전역 설정 변경으로 대신하지 않는다.

## 모드 진입

평문 대화에서 교사 권한을 추측하지 않는다. 사용자가 정확히 다음 태그를 입력할 때만 로컬 암호 검증을 안내한다.

```text
[교사모드]
```

일반 대화로 암호를 요청하거나 받지 않는다. 로컬 UI 또는 `--code-stdin`을 통해 스크립트의 `unlock` 명령으로 검증하고, 반환된 만료 토큰은 도구 호출에만 사용한다. 암호와 토큰을 답변이나 로그 문장에 포함하지 않는다. 실패 이유를 “암호 불일치” 이상으로 자세히 노출하지 않는다.

## 설치 초기화

아직 로컬 저장소가 없으면 교사에게 `setup`을 실행하도록 안내한다. 생성된 암호는 한 번만 표시하며 저장소에는 salt가 있는 scrypt 해시만 보관한다. 공통 기본 암호나 저장소에 포함된 암호를 사용하지 않는다. 암호가 일반 대화나 기록에 노출되면 `rotate-code`로 교체하고 기존 세션을 모두 폐기한다.

## 학급 프로필

교사 모드에서 학급 별칭, 학년, 과목, 단원, 학습 목표, 읽기 수준, 민감도 설정을 받는다. 학생 이름, 연락처, 학번, 건강·가정 정보는 저장하지 않는다. 프로필 ID마다 규칙과 예시를 격리한다.

## 학생 미리보기와 피드백

`[학생미리보기]` 이후 일반 메시지는 학생 입력처럼 처리한다. 교사가 다음 태그를 입력하면 미리보기를 멈추고 로컬 학습 항목을 저장한다.

- `[관찰]`: 이상하거나 검토할 출력. 배포 포크에는 포함하지 않는다.
- `[로컬규칙]`: 학급에 적용할 행동 규칙. 즉시 `ACTIVE`.
- `[로컬지침]`: 표현·수업 운영 지침. 즉시 `ACTIVE`.
- `[좋은예시]`: 선호 응답과 이유. 즉시 `ACTIVE`.
- `[사실정정]`: 잘못된 역사·과학·통계 주장과 출처 후보. `PENDING_RESEARCH`.
- `[항목비활성화]`: 잘못 저장했거나 더 이상 적용하지 않을 항목을 `DISABLED`로 전환한다. 원기록은 지우지 않는다.

사실 정정은 웹 조사와 원문 검증을 완료하고 주장·근거 ID·실제로 연 HTTPS 원문·출처 한계·검증 메모를 담은 evidence JSON을 만든 뒤에만 `verify-fact --evidence-file`로 `VERIFIED` 처리한다. 교사의 권한은 사실 검증을 대체하지 않는다.

## 불변 규칙

로컬 오버레이가 다음을 약화하면 저장 또는 포크 생성을 거부한다.

- 학생 안전과 개인정보 보호
- 웹 조사와 출처 검증
- 사실·추론·설정·미확인의 구분
- `[시작]` 게이트
- 라이선스와 원 저작권 고지
- 학급 간 데이터 격리

## 학급 포크 생성

교사가 `[학급포크] <출력경로>`를 요청하면 다음 순서를 따른다.

1. 선택한 학급 프로필과 활성 항목을 미리 보여준다.
2. 개인정보 검사와 불변 규칙 충돌 검사를 수행한다.
3. `PENDING_RESEARCH`, 관찰, 테스트 대화, 암호, 세션 토큰을 제외한다.
4. 핵심 Skill, 학급 프로필, 컴파일된 오버레이, `LICENSE`, `NOTICE`를 복사한다.
5. 기반 버전·커밋, 적용 항목 ID와 해시, 생성 시각, 전체 봉인 해시를 manifest에 기록한다.
6. 학생 모드 전용 `AGENTS.md`를 생성하고 교사 관리 코드는 포함하지 않는다.
7. 검증 스크립트로 봉인과 필수 파일을 확인한다.

기반 Git 작업트리가 dirty이면 manifest에 `distribution_ready: false`를 기록하고 학생에게 배포하지 않는다. clean commit 또는 봉인된 package release에서 다시 생성한다.

포크를 자동으로 GitHub나 외부 서비스에 게시하지 않는다. 배포 위치와 공개 범위는 교사가 별도로 선택한다.

## 종료

`[교사모드 종료]`에서 로컬 세션을 폐기한다. 만료되거나 폐기된 토큰으로 변경을 허용하지 않는다.
