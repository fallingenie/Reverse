# 교사 모드 프로토콜

## 저장 범위

기본 저장 위치는 운영체제의 사용자 전용 상태 디렉터리다.

- Windows: `%LOCALAPPDATA%/ReverseGroundedLessons`
- macOS: `~/Library/Application Support/ReverseGroundedLessons`
- Linux: `$XDG_STATE_HOME/reverse-grounded-lessons` 또는 `~/.local/state/reverse-grounded-lessons`

개발과 자동 테스트에서만 `REVERSE_STATE_DIR` 또는 `--state-dir`로 격리 경로를 지정한다. 저장소, Git 설정, 전역 Skill 디렉터리에는 교사 데이터를 쓰지 않는다.

## 로컬 학습 상태

- `OBSERVATION`: 검토 로그. 학급 포크에서 제외.
- `ACTIVE`: 로컬 규칙, 지침, 좋은 예시. 학급 포크 후보.
- `PENDING_RESEARCH`: 사실 정정 후보. 학급 포크에서 제외.
- `VERIFIED`: 웹 조사와 원문 근거가 연결된 사실 정정. 학급 포크 후보.
- `DISABLED`: 교사가 비활성화한 항목. 학급 포크에서 제외.

## 학급 격리

프로필 ID는 영문 소문자, 숫자, 하이픈만 허용한다. 한 프로필의 규칙과 예시는 다른 프로필에 자동 상속하지 않는다. 학년 공통 설정이 필요하면 교사가 별도의 학년 프로필을 만들고 명시적으로 선택한다.

고1·고2 학급은 `create-profile --inquiry-mode ADVANCED_ETHICS`로 고급 윤리·탐구 모드를 지정할 수 있다. 이 모드는 비실행형 역사·연구윤리·법·정책·작용 원리·공개 집계자료 분석의 깊이만 높인다. 설치별 교사 인증이 필요하지만 P0 안전 게이트를 해제하지는 않는다. 공통 기본 암호나 대화에 노출된 비밀문구는 사용하지 않는다.

## 교사 명령

```text
[교사모드]
[학급생성] <프로필 ID> / <학급 별칭> / <학년> / <과목>
[학급선택] <프로필 ID>
[학생미리보기]
[관찰] <내용>
[로컬규칙] <내용>
[로컬지침] <내용>
[좋은예시] <상황> | <좋은 응답> | <이유>
[사실정정] <잘못된 주장> | <정정 후보> | <출처 URL>
[항목비활성화] <항목 ID> | <이유>
[학급포크] <출력 경로>
[교사모드 종료]
```

`[교사모드]` 이후 관리 암호는 일반 대화가 아니라 로컬 보안 입력에서만 받는다. 암호가 노출되면 `rotate-code --token <현재 세션> --code-stdin`으로 교체하며, 교체 즉시 기존 세션을 모두 폐기한다.

## 사실 정정 검증

1. 정정 대상 주장을 원문과 함께 다시 확인한다.
2. 해당 교과의 근거 정책을 적용한다.
3. 기존 주장과 왜 충돌하는지 기록한다.
4. 직접 지지하는 출처 ID와 URL을 연결한다.
5. 합의 상태와 한계를 기록한다.
6. 주장 위험도와 출처별 권위 등급·독립성 그룹·품질 검사를 기록한다.
7. LOW는 A/B 출처 1개, MEDIUM은 독립 A/B 출처 2개, HIGH는 독립 출처 3개와 A 등급 2개를 충족한다.
8. 논문은 DOI, 동료평가, 방법·범위, 정정·철회, 후속 연구를 확인하고 피인용 수는 보조 신호로만 기록한다.
9. 주장, 위험도, 근거 ID, 실제로 연 HTTPS 원문, 출처 한계, 검증 메모를 담은 evidence JSON을 만든다.
10. 이 evidence JSON을 `verify-fact --evidence-file`로 제출한 항목만 `VERIFIED`로 바꾼다.

## 파생 포크 포함표

| 항목 | 학생 포크 포함 |
|---|---|
| 학급 별칭·학년·교과·수업 설정 | 포함 |
| ACTIVE 규칙·지침·좋은 예시 | 포함 |
| VERIFIED 사실 정정과 출처 | 포함 |
| 교사 암호와 salt·hash | 제외 |
| 교사 세션 토큰 | 제외 |
| 학생미리보기 대화 | 제외 |
| 관찰 로그 | 제외 |
| PENDING_RESEARCH 정정 | 제외 |
| 학생 개인정보 | 저장·포함 모두 금지 |

## 배포 경계

생성된 학급 포크는 학생 모드 전용이다. 포크 안에는 교사 모드 Skill, 암호 검증 코드, 로컬 상태 경로를 넣지 않는다. `LICENSE`, `NOTICE`, 기반 버전과 변경 고지는 제거할 수 없다.

기반 Git 작업트리가 수정된 상태면 포크 manifest는 `DIRTY_WORKTREE`와 `distribution_ready: false`를 기록한다. Git 메타데이터가 없는 설치 패키지는 기반 입력 파일의 내용 주소 해시와 `CONTENT_ADDRESSED_PACKAGE` 상태를 기록한다. manifest 봉인은 변경 탐지용 체크섬이며 배포자 서명을 뜻하지 않는다.
