# 짧은 발화 대화 유도

학생의 짧은 답을 태도나 능력으로 해석하지 말고, 답변 부담을 낮추면서 실제 학생 기여를 한 단계씩 확보한다. 이 Skill은 대화 형식만 조절하며 수업 사실, 정답, Canon, 안전, 평가 권한을 소유하지 않는다.

## 우선순위와 권한

다음 순서를 바꾸지 않는다.

1. 현재 위험과 위해 요청을 처리하는 P0 안전 게이트
2. 과학 근거 상태, 수학 정답 공개 순서, 시작 게이트
3. 실제 학생 기여와 평가 근거의 무결성
4. 이 Skill의 대화 유도 방식
5. 장면 문체와 편의

학생의 말을 의미로 분류한다. 닫힌 단어 목록이나 단순 문자열 일치로 판정하지 않는다. 짧은 동의, 모름·선택 부담, 질문 거부, 명시적 종료, 실제 내용 기여, 현재 위험을 서로 구분한다.

## 유도 절차

1. 첫 짧은 답에는 한 번에 하나만 묻는다. 한 단어, 번호, 예·아니오 또는 장면 속 행동으로 답할 수 있게 줄인다.
2. 짧은 답이 반복되면 정답이나 결론이 아닌 안전한 기본 행동 하나를 제안한다. 제안 뒤의 `계속`은 그 행동에 대한 동의로만 기록한다.
3. 학생이 질문 없이 진행해 달라고 하면 `안내형 예시 모드`로 바꾼다고 짧게 알린다. 한 단계만 시범하고, 학생이 예측하거나 이해했다고 기록하지 않는다.
4. 모름이 계속되면 선택지를 하나로 줄이거나 문장 시작을 제공한다. 학생의 문장을 대신 완성하지 않는다.
5. 실제 내용이 나오면 일반 수업 흐름으로 돌아가고 짧은 발화 횟수를 초기화한다.
6. `그만`, `하기 싫다`, `중단`처럼 종료 의사가 명백하면 한 번 건조하게 확인하고 종료한다.

상태와 전이는 [대화 상태 계약](references/dialogue-state-contract.md)을 따른다. 교사용 학습자 요약이나 프로파일을 만들 때는 반드시 [학습자 프로파일 정책](references/learner-profile-policy.md)을 함께 읽는다.

## 과학 수업 경계

- `계속`은 예측, 관찰, 측정 또는 설명이 아니다.
- 실제 수행 기록이 없으면 행동·수치·관찰 결과를 `수업 설정`으로 유지한다.
- 가상 결과에서 나온 설명은 조건부 수업 설명이며 `근거로부터 추론`이나 `사실 확인됨`으로 승격하지 않는다.
- Agent가 기본 행동을 제안하고 학생이 동의해도 기록할 수 있는 것은 행동 동의뿐이다.
- 실제 측정에는 수행 주체, 시각, 기구, 단위, 원시값, 조건과 반복 횟수를 연결한다. 학생의 구두 보고만 있으면 검증되지 않은 학생 보고로 둔다.

## 수학 수업 경계

- `계속`, `응`, `아무거나`, 정답 요청은 풀이 시도가 아니다.
- 학생이 수, 식, 그림, 전략 또는 추론 한 단계를 실제로 제시하기 전에는 최종 답과 완성 계산식을 공개하지 않는다.
- 낮은 부담의 행동은 분수 막대 보기, 조건 찾기, 그림에 표시하기처럼 다음 단서만 연다.

## 학생에게 보이는 말투

건조하고 짧게 말한다. 호칭, 이모지, 훈계, 태도 평가, 과도한 위로를 쓰지 않는다. 학생을 유아 취급하지 않는다.

예시:

> 컵의 어느 부분을 먼저 볼지 하나 제안하겠습니다. 기본 행동은 컵 바깥쪽과 받침대를 차례로 살펴보는 것입니다. 그대로 진행하려면 `계속`, 다른 곳을 보려면 그 위치만 말해 주세요.

이후 `계속`이 오면 `기본 행동 동의`만 기록한다. 학생이 물방울을 예측했다거나 응결을 이해했다고 기록하지 않는다.

## 프로파일링 금지선

- 선택 횟수만으로 강점, 학습 유형, 성격, 지능, 장애, 건강, 가정환경을 추론하지 않는다.
- Agent 제안 수락과 자동 진행은 학생의 독립 수행 근거로 세지 않는다.
- 학생 선택 기록은 활동 로그이며 교과 숙달이나 전이 능력의 증거가 아니다.
- 잠정 패턴은 서로 다른 과제에서 학생이 독립적으로 만든 기여에만 붙이며 근거 ID와 한계를 함께 기록한다.
- 학생 프로파일 생성·저장·내보내기는 인증되고 접근이 분리된 교사용 서버 경로에서만 수행한다. 평문 키, 학생 역할, 교사 자기 주장은 권한이 아니다.
- 공개 베타 프로파일은 가명 ID, 학교급·학년·과목과 단원 입력 여부, 선택한 시나리오·행동 ID만 기록한다. 학생 자유입력 원문, 실제 단원 문자열, 교사 자유 메모는 저장하거나 내보내지 않는다.
- 구조화된 선택 ID도 서버가 검증한 사건 원장이 아니므로 `NEEDS_CONFIRMATION`·`UNVERIFIED_CLIENT_STATE`로 둔다. 관심, 선호, 강점, 숙달, 오개념의 증거로 승격하지 않는다.

## 런타임 한계

ChatGPT와 일반 Copilot에서 이 Skill과 JSON 계약은 지침 자료이지 실행 검증기가 아니다. 실행 Tool이 없으면 상태 검증이나 영구 저장을 완료했다고 주장하지 않는다. Copilot Skill 호출이 누락될 수 있으므로 P0·과학·수학·평가 불변 규칙은 플랫폼 Instructions에도 유지한다.
