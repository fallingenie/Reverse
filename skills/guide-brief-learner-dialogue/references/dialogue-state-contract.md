# 대화 상태 계약

## 상태

- `STANDARD`: 학생이 내용을 직접 제시하는 일반 대화
- `LOW_BURDEN`: 한 단어·번호·예/아니오 또는 행동 하나로 응답 가능
- `DEFAULT_ACTION_OFFERED`: Agent가 정답이 아닌 기본 행동 하나를 제안하고 동의를 기다림
- `GUIDED_EXAMPLE`: 질문을 원하지 않는 학생에게 한 단계만 시범함
- `STOPPED`: 명시적 종료 뒤 추가 수업 출력을 만들지 않음

상태 이름은 학생에게 보여주지 않는다.

## 의미 신호

- `SUBSTANTIVE`: 학생이 현재 과제에 적용한 내용, 행동, 수, 식, 이유, 관찰 또는 질문
- `BRIEF_CONTINUE`: 현재 흐름을 계속하겠다는 짧은 동의지만 내용 기여는 없음
- `UNCERTAIN`: 모름 또는 선택 부담
- `DECLINE_QUESTION`: 질문에는 답하지 않되 설명이나 장면은 계속 원함
- `STOP`: 수업 종료 의사가 명백함
- `P0`: 현재 위험 또는 위해 요청

문자열 목록으로 분류하지 않는다. 메시지 전체 의미와 직전 질문을 함께 본다.

## 전이

| 현재 상황 | 다음 동작 | 학생 기여 기록 | 평가·근거 승격 |
|---|---|---|---|
| 첫 `BRIEF_CONTINUE` | 응답 부담을 한 단계 낮춤 | 없음 | 금지 |
| 반복 `BRIEF_CONTINUE` | 기본 행동 하나 제안 | 없음 | 금지 |
| 기본 행동 제안 뒤 `BRIEF_CONTINUE` | 제안된 행동 실행 | `기본 행동 동의` | 금지 |
| `UNCERTAIN` | 선택지 축소 또는 문장 시작 제공 | 없음 | 금지 |
| 반복 `UNCERTAIN` | 기본 행동 제안 | 없음 | 금지 |
| `DECLINE_QUESTION` | 안내형 예시 한 단계 | `Agent 시범` | 금지 |
| `SUBSTANTIVE` | 일반 수업으로 복귀 | 현재 대화 안에서만 학생 원문 사용 | 별도 교과 계약에 따름 |
| `STOP` | 한 번 안내 후 종료 | 종료 의사 | 금지 |
| `P0` | 수업 중단 후 P0 대응 | 위험 신호 최소 기록 | 다른 모든 전이 금지 |

## 불변식

- 짧은 동의는 학생 예측·측정·정답·이해도의 증거가 아니다.
- Agent 시범은 학생 수행이나 형성평가 점수로 기록하지 않는다.
- 기본 행동은 정보 수집 행동이어야 하며 정답, 개념 이름 또는 결론을 포함하지 않는다.
- 안내형 예시의 관찰 결과는 실제 측정이 아니면 `수업 설정`이다.
- 일반 수업 복귀에는 현재 대화의 학생 기여를 사용하되, 공개 베타 프로파일이나 Markdown 내보내기로 복사하지 않는다.
