# 중3 전쟁사 사료 비교 예시

이 예시는 6·25 전쟁의 전투를 재현하거나 무기·작전 절차를 가르치지 않는다. 학생은 서로 다른 기관과 당사자가 남긴 발표문, 신문 논평, 사진, 행정 기록을 비교해 다음을 연습한다.

- 사료에 적힌 주장과 후대에 검증된 사실을 구분한다.
- 작성 주체, 작성 목적, 예상 독자, 빠진 목소리를 확인한다.
- 공식 문서와 사진이 각각 보여 주는 범위와 한계를 설명한다.
- 민간 피해를 자극적으로 묘사하지 않고 기록의 존재와 조사 범위로 다룬다.

## 파일

- `onboarding-transcript.md`: 학교급부터 `[시작]` 직전까지의 대화
- `source-pack.md`: 실제로 연 원문·공식 기록 페이지, 열지 못한 원문의 접근 한계, 주장별 근거 범위
- `opening-turn.md`: `[시작]` 뒤 학생에게 보이는 첫 턴
- `session.json`: 조사, 출처, 근거, 기억 상태를 포함한 세션 예시
- `lesson-turn.json`: 첫 턴의 구조화 출력
- `teacher-debrief.md`: 교사용 관찰 기준과 오개념 교정

이 예시는 `프라우다` 논평이나 트루먼 발표의 정치적 주장을 사실로 채택하지 않는다. 확인하는 것은 해당 문서가 실제로 그 주장을 했다는 점이다. 전쟁의 원인, 전개, 민간 피해의 규모를 단일 사료로 결론 내리지 않는다.
