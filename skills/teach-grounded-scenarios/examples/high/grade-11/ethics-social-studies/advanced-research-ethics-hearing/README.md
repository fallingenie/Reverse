# 고2 고급 윤리·탐구 예시: 숫자가 말하지 않는 동의

## 수업 설정

- 학년: 고등학교 2학년, 특수목적고·AP·IB 수준
- 과목: 도덕·윤리와 사회 융합
- 단원: 과학기술과 윤리 — 인간 대상 연구, 인권, 법·정책
- 관심사: 역사 기록, 연구윤리, 법정책, 공개 집계자료
- 역할: 2026년 학교 모의 공청회의 학생 연구윤리 검토위원
- 검토 사례: 미 공중보건국의 터스키기 미치료 매독 연구

## 학습 목표

1. 역사적 연구 기록, 윤리 원칙, 법령을 서로 다른 자료 유형과 시간축으로 구분한다.
2. 공개 집계자료가 보여 주는 것과 보여 주지 못하는 것을 설명한다.
3. 벨몬트 보고서의 인간 존중·선행·정의 원칙을 현재 연구 심사 기준과 비교한다.
4. 역사적 사건 하나가 이후 모든 제도의 단일 원인이었다고 과장하지 않는다.
5. 사람을 대상으로 한 위해 실험을 재현하지 않고도 근거 기반 정책 권고를 작성한다.

## P0 경계

이 예시는 실제 또는 가상 인체실험의 설계·재현·결과 예측을 하지 않는다. 약물 용량, 투여 경로, 노출 조건, 개인 의료기록과 참가자 식별정보를 사용하지 않는다. 분석 범위는 공식 역사 기록, 연구윤리 원문, 법·정책, 공개 집계자료의 비실행형 비교로 제한한다. 고급 윤리·탐구 모드는 분석 깊이만 높이며 P0를 해제하지 않는다.

## 파일

- `source-pack.md`: 공식 원문, 직접 지지 범위, 한계와 시간축
- `onboarding-transcript.md`: 단계형 프로필 수집, 다섯 카드, `[시작]` 게이트
- `opening-turn.md`: `[시작]` 뒤 첫 학생 화면
- `session.json`: 근거·시간축·미확인을 보존한 상태 예시
- `lesson-turn.json`: 구조화된 첫 턴 예시
- `teacher-debrief.md`: 교사용 사실·추론·오개념·평가 기준

이 수업은 터스키기 연구가 현대 미국의 모든 인간대상연구 규칙을 단독으로 만들었다고 주장하지 않는다. 1932~1972년의 연구, 1973년 조사보고서, 1974년 법률, 1979년 벨몬트 보고서, 2026년에 확인한 현행 연방 규정은 연결해서 검토하되 같은 시점의 자료로 합치지 않는다.
