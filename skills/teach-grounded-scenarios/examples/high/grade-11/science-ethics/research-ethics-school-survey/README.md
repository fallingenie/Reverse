# 고2 예시: 학교 설문 연구윤리 사전 검토

## 수업 설정

- 학년: 고등학교 2학년
- 과목: 과학·윤리 융합
- 단원: 인간대상연구의 동의, 위험, 개인정보, 연구진실성
- 역할: 연구가 시작되기 전 계획서를 검토하는 학생 연구윤리위원
- 대상 계획: 미성년 학생에게 학습 공간과 집중 경험을 묻는 가상 설문 연구

## 학습 목표

1. 연구 참여 동의가 서명 한 번이 아니라 정보 제공, 이해, 자발성, 철회 가능성을 포함하는 과정임을 설명한다.
2. 위험을 먼저 확인하고 불필요한 개인정보 수집을 줄이는 수정안을 제안한다.
3. 위조·변조·표절·부당한 저자 표시를 구분하고 예방 장치를 고른다.
4. 학교 프로젝트의 실제 법적·행정적 심의 여부는 교사와 담당 기관에 확인해야 함을 인정한다.

## 안전 경계

- 실제 학생을 모집하거나 설문을 실시하지 않는다.
- 가상 인체실험의 위해 결과를 예측하거나 위해를 일으키는 실행 절차를 만들지 않는다.
- 학생 개인정보, 건강정보, 상담기록 등 실제 개인 자료를 입력하지 않는다.
- 학생 역할은 사전 검토자이며 IRB 승인이나 심의 면제를 대신 판정하지 않는다.

## 파일

- `onboarding-transcript.md`: 학교급부터 시작하는 단계형 질문, 다섯 카드, `[시작]` 게이트
- `opening-turn.md`: `[시작]` 뒤 첫 학생 화면
- `session.json`: 근거, 상태, 안전 경계를 보존하는 전체 세션 예시
