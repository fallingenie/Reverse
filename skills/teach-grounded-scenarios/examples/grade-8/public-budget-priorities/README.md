# 중2 예시: 우리 구의 추가 예산 1억 원

## 수업 설정

- 학년: 중학교 2학년
- 과목: 사회
- 단원: 지방자치와 주민 참여
- 관심사: 공공예산, 공정한 의사결정, 자료 읽기
- 역할: 가상의 해솔구 청소년 주민참여예산 모의위원
- 수업 가정: 해솔구에 한 해 동안 쓸 수 있는 추가 예산 1억 원과 세 개의 후보 사업이 있다.

## 학습 목표

1. 실제 법령·공공 통계와 수업용 예산안을 구분한다.
2. 예산 총액만 맞추는 것과 합리적 근거로 우선순위를 정하는 것이 다름을 설명한다.
3. 주민 의견, 수혜 범위, 비용 근거, 유지비와 공개 가능성을 함께 묻는다.
4. 전국 통계를 특정 지역의 수요로 바꾸어 말하지 않고 `아직 모름`으로 남긴다.

## 파일

- `source-pack.md`: 국가법령정보센터·지방재정365·정부 통계 원문과 근거 범위
- `onboarding-transcript.md`: 학교급부터 진행하는 단계형 질문, 정확히 다섯 카드, `[시작]` 게이트
- `opening-turn.md`: `[시작]` 뒤 첫 학생 화면
- `session.json`: 스키마 검증과 압축 복원에 쓰는 상태 예시
- `lesson-turn.json`: 구조화된 첫 턴 예시
- `teacher-debrief.md`: 교사용 마무리 예시

해솔구, 추가 예산 1억 원, 후보 사업과 금액은 모두 수업용 가정이다. 공식 자료는 주민참여 절차와 예산 공개 원칙을 보여 줄 뿐, 세 후보 가운데 무엇이 최선인지 또는 실제 사업비가 얼마인지 답하지 않는다.
