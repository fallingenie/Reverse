# 초5 예시: 숲길에서 동물의 흔적을 조사하기

## 수업 설정

- 학년: 초등학교 5학년
- 과목: 과학·환경
- 학생 입력 단원: 생물과 환경
- 관심사: 숲, 동물의 흔적, 사진 기록
- 수업 모드: 비접촉 생태 조사
- 장소: 교사가 사전에 허가와 안전을 확인한 낮 시간의 공개 숲길

## 학습 목표

1. 직접 본 동물과 동물이 남긴 흔적을 구분해 기록한다.
2. 날짜, 장소, 시간, 날씨, 관찰 시간을 맞춰야 두 관찰을 비교하기 쉬워짐을 설명한다.
3. 한 번 보지 못한 것을 곧바로 “없다”라고 결론 내리지 않는다.
4. 야생동물과 서식지를 만지거나 먹이를 주지 않고 거리를 두어 관찰한다.

## 파일

- `source-pack.md`: 국립생태원·산림청·대학·동료평가 논문의 근거와 한계
- `onboarding-transcript.md`: 학교급부터 진행하는 단계형 질문, 다섯 카드, `[시작]` 게이트
- `opening-turn.md`: `[시작]` 뒤 첫 학생 화면
- `session.json`: 조사 계획, 출처, 근거, 기억을 포함한 상태 예시
- `lesson-turn.json`: 구조화된 첫 턴 예시
- `teacher-debrief.md`: 교사용 마무리와 오개념 점검

이 예시는 야생동물의 포획, 접촉, 먹이주기, 둥지·배설물·털·깃털 수집을 요구하지 않는다. 학생은 교사와 함께 지정된 길에서 눈과 귀로 관찰하고, 모르는 종은 억지로 이름 붙이지 않는다. 한 차례의 짧은 관찰로 숲 전체의 종 수, 개체 수, 건강 상태를 판정하지 않는다.
