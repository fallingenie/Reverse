# 초6 예시: 원자폭탄이 없었던 1945년 8월

## 수업 설정

- 학년: 초등학교 6학년
- 과목: 사회
- 관심사: 평범한 사람의 생활과 선택
- 역할: 1945년 일제 강점기 조선의 경성에 가족과 사는 평범한 조선인 A
- 분기점: 미국의 핵무기 개발이 실패하여 히로시마와 나가사키에 원자폭탄이 투하되지 않는다.
- 시작 날짜: 1945년 8월 10일

## 학습 목표

1. 실제 사실과 반사실 가정을 구분한다.
2. 하나의 역사적 결과에 여러 원인이 작용할 수 있음을 설명한다.
3. 당시 평범한 사람이 알 수 있었던 정보와 오늘날 아는 정보를 구분한다.
4. 자료가 답하지 못하는 질문을 `UNKNOWN`으로 남긴다.

## 파일

- `source-pack.md`: 공식 출처와 근거 범위
- `onboarding-transcript.md`: 세 질문, 다섯 카드, `[시작]` 게이트
- `opening-turn.md`: `[시작]` 뒤 첫 학생 화면
- `session.json`: 압축과 스키마 검증에 쓰는 상태 예시
- `lesson-turn.json`: 구조화된 첫 턴 예시
- `teacher-debrief.md`: 교사용 마무리 예시

이 예시는 원자폭탄이 일본의 항복에 영향을 주지 않았다고 주장하지 않는다. 반대로 원자폭탄만이 유일한 원인이었다고도 단정하지 않는다. 분기 이후의 항복 시점, 해방 시점, 점령과 분단의 경로는 열린 질문으로 유지한다.
