# Story Track과 Canon 교정

## 원칙

기본 추론이나 사실 전제가 틀렸음을 확인하면 즉시 인정하고 장면 진행을 멈춘다. 실제 역사·과학 기록과 Story Canon을 구분한다. 오류를 자연스럽게 보이도록 새 설정으로 덮거나 과거 기록을 삭제하지 않는다.

모든 교정은 다음을 남긴다.

- 교정 ID와 발견 계기
- 잘못된 주장·Canon·에피소드 ID
- 검증된 대체 내용과 근거 ID
- 오류가 영향을 준 시간선, 인과, 선택, 제약, 열린 질문
- 마지막으로 유효한 체크포인트
- 적용 방식과 사용자 결정

원래 기록은 `superseded`로 남기고 최신 교정이 현재 상태에서 우선한다.

## 영향 등급

### `LOCAL_PATCH`

인물의 나이, 단일 수치, 제한된 원인 설명처럼 오류의 영향이 좁고 핵심 전제와 학생 선택의 의미가 유지된다. 교정을 알리고 관련 Canon·파생 주장·현재 상태만 다시 계산한다. 사용자의 선택을 소급해서 바꾸지 않는다.

### `TRACK_REBASE`

오류가 여러 에피소드의 연표나 인과에 퍼졌지만 핵심 학습 목표와 분기점은 유지된다. 진행을 일시 정지하고 영향 목록과 마지막 유효 체크포인트를 보여준다. 사용자에게 다음 중 선택을 받는다.

1. 체크포인트에서 교정된 Track으로 다시 이어가기
2. 영향받은 구간을 짧게 재구성하고 현재 지점에서 계속하기
3. 기존 구간을 명시적인 가상 설정으로 보존하기

### `RESTART_RECOMMENDED`

핵심 분기점, 시대·장소, 물리 법칙, 주요 인물 조건, 학습 목표를 지탱하는 근거가 무너져 부분 수선이 더 많은 허구를 만들 때 사용한다. 잘못된 Track을 계속 생성하지 않는다. 오류 사유, 보존 가능한 학생 선택·근거·교정, 재시작 지점을 설명하고 다음 옵션을 제시한다.

1. 마지막 유효 체크포인트에서 재시작
2. 같은 학습 목표로 새 시나리오 선택
3. 문제 있는 전제를 `SCENARIO`로 명시하고 대안적 허구로 계속
4. 수업을 중단하고 현재까지의 사실·오류를 정리

재시작이나 Track 폐기는 사용자의 명시적 선택 전에는 실행하지 않는다.

## 교정 전파

교정 적용 뒤 다음을 함께 확인한다.

1. `memory.canon`의 현재 우선 레코드
2. 교정 대상에서 도출된 `DERIVED` 주장
3. 시간, 장소, 자원, 관계, 건강·기술·제도 제약
4. 영향받은 에피소드와 학생 선택의 의미
5. 부정 사실과 열린 질문
6. 압축 요약의 보존 ID와 세션 revision

하나라도 다시 계산하지 못하면 충돌을 숨기지 말고 `UNKNOWN`과 미해결 항목으로 남긴다.
