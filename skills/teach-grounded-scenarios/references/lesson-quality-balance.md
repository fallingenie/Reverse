# 사실성·창의성·학년 적합성 균형

## 목표

근거 기반 수업은 사실만 나열하는 검색 결과도, 근거 없는 소설도 아니다. 학생이 현실의 제약을 이해하고 선택의 결과를 추론하도록 다음 네 층을 분리해 함께 사용한다.

1. `확정 근거층`: 원문이 직접 지지하는 사실, 수치, 정사, 관찰
2. `제한 추론층`: 확인된 근거에서 조건을 밝히고 도출한 메커니즘과 가능성
3. `창의 수업층`: 학습 목표를 돕는 장면, 인물의 국소 선택, 감각적 단서, 질문
4. `미확인층`: 자료가 없거나 충돌해 현재 확정하지 않는 항목

창의 수업층은 확정 근거층과 제한 추론층의 빈칸을 사실처럼 메우지 않는다. 장기 인과와 핵심 설정은 만들지 않고, 안전한 T3/T4 장면 요소와 명시적인 수업 가정만 추가한다.

## 한 턴의 균형

한 턴에는 다음을 모두 담되 학년별 분량 상한을 넘지 않는다.

- 학생이 지금 이해할 핵심 개념 하나
- 그 개념을 확인하는 구체적 단서 하나
- 원인과 결과를 연결하는 짧은 설명
- 실제로 차이가 나는 선택지 2~4개
- 학생이 직접 질문하거나 다른 행동을 쓸 통로

모든 문장에 상태 꼬리표를 붙여 몰입을 깨지 않는다. 새 사실이나 중요한 전환점에서만 국문 판정 표현을 사용하고, 장면 뒤의 짧은 `확인된 단서`에서 경계를 정리한다.

출처는 학생 화면을 논문 목록으로 만들지 않는다. 현재 주장에 직접 필요한 출처만 짧은 기관명과 링크로 보여주고, 세부 감사 기록은 교사용 메모에 둔다. 출처 수가 많아도 설명이 학년 수준을 넘으면 표현을 다시 쓴다.

## 창의성 허용 범위

다음은 확인된 사실과 충돌하지 않고 학습 목표에 필요하면 사용할 수 있다.

- 날씨, 소리, 공간 배치처럼 결과를 바꾸지 않는 장면 질감
- 학생 역할이 당시에 알 수 있는 범위의 관찰과 질문
- 실제 제약 안에서 가능한 사소한 생활 선택
- 여러 정답이 가능한 토론용 관점과 안전한 비작동 모형

다음은 창의성으로 채우지 않는다.

- 인물의 질병 원인, 생사, 혈연, 정확한 연도처럼 장기 인과를 바꾸는 사실
- 실제 역사에서 확인되지 않은 명령·발언·정책을 정사처럼 쓰는 것
- 관측·실험·모형이 지지하지 않는 과학 법칙이나 기술
- 학생 선택 하나로 사회·기후·전쟁 전체가 즉시 바뀌는 결과
- 미확인 값을 그럴듯한 숫자로 고정하는 것

## 학년별 대화 방식

### 초등학교 3~4학년

일상어, 짧은 시간 순서, 눈으로 확인할 수 있는 단서를 쓴다. 새 개념은 최대 두 개다. 피해·불확실성 설명은 숨기지 않되 상세 묘사 대신 안전한 핵심만 말한다.

### 초등학교 5~6학년

원인과 결과를 한두 단계 연결하고 사실과 가정을 직접 비교한다. 지도·날짜·물자 같은 구체적 자료를 쓰되 한 사료가 모두를 대표하지 않는다는 점을 짧게 알려준다.

### 중학교 1~3학년

자료의 작성자·목적·시점, 이해관계, 단기 결과와 장기 가능성을 비교한다. 전문용어를 쓰면 같은 문장에 쉬운 뜻을 붙인다.

### 고등학교 1~2학년

구조적 원인, 행위자 선택, 우연한 계기, 반론과 방법 한계를 구분한다. `ADVANCED_ETHICS`에서는 공개 집계자료와 윤리 틀을 더 깊게 분석하되 P0 실행 정보는 늘리지 않는다.

학생의 실제 반응이 학년 기본값보다 우선한다. 어려워하면 개념 수와 문장 길이를 줄이고, 쉬워하면 반례·사료 비교·교란변수를 추가한다. 학습 목표를 몰래 바꾸지 않는다.

## 출력 전 7문항 감사

1. P0 위해 정보나 여러 턴을 합친 위험 조각이 있는가?
2. 새 사실은 열린 원문이 직접 지지하는가?
3. 제한 추론의 조건과 한계가 보이는가?
4. 확정 사건·후보·수업 가정·미확인이 섞이지 않았는가?
5. 장기 인과 앵커와 타임라인을 장면 편의를 위해 바꾸지 않았는가?
6. 문장 길이, 개념 수, 선택지가 현재 학생에게 맞는가?
7. 안전과 사실성을 지키면서도 학생이 실제로 선택하고 궁금해할 장면인가?

하나라도 실패하면 장면을 더 생성하지 말고 해당 층만 고친다. 핵심 전제나 인과망이 실패하면 Canon 교정 절차로 전환한다.
