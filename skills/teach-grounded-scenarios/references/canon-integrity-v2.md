# 장기 Canon 무결성 v2

## 상태 구분

- `PRESENT`: 필요한 ACTIVE 사실이 현재 Context에 있다.
- `NOT_LOADED`: 기존 사실이 원장에 있을 수 있으나 현재 Context에 없다.
- `UNKNOWN_LOCKED`: 필요한 근거 또는 사용자 결정 전에는 채우지 않기로 고정했다.
- `NOT_ESTABLISHED`: 아직 설정하거나 검증한 적이 없다.
- `CONFLICTED`: 서로 양립할 수 없는 기록이 있다.
- `BROKEN_REFERENCE`: 참조한 ID나 해시가 없다.
- `SUPERSEDED`: 명시적 교정으로 대체됐으며 원본은 보존된다.

`NOT_LOADED`, `UNKNOWN_LOCKED`, `NOT_ESTABLISHED`를 창작 허가로 취급하지 않는다.

## 내구성

- `T0`: 수업의 현실 기준, 분기점, 핵심 안전·교육 정책
- `T1`: 장기 인물·기관·인과 앵커
- `T2`: 현재 에피소드의 지속 상태
- `T3`: 장면 수준 상태
- `T4`: 버려도 되는 표현·분위기

T0/T1은 외부 호스트의 권한 검사와 필요한 사용자 승인을 통과해야 한다. 프롬프트 기반 런타임은 후보만 쓴다.

## Context 폐쇄성

장면에 필요한 사실 ID에서 `caused_by`를 재귀적으로 따라가 모든 원인 앵커를 포함한다. 하나라도 ACTIVE 상태로 읽히지 않으면 Context Pack은 `BLOCKED`다. 벡터 검색은 후보 발견에만 쓸 수 있으며 ID·해시·인과 폐쇄 검사를 대신하지 않는다.

## 상태 동일성

두 기록을 같은 사실로 합치거나 `CONFLICTED`로 표시하기 전에 다음 키를 비교한다.

1. 대상과 소유 주체
2. 의미 필드와 상태 종류
3. 값의 단위와 척도
4. 기준면·기준 상태
5. 측정·관찰 조건
6. 유효 시점과 기간
7. 출처와 직접성

표현이나 숫자가 비슷하다는 이유만으로 동일성을 부여하지 않는다. 예를 들어 `새 자택은 2층`과 `지면에서 한 층을 오른다`는 주택 층수와 이동 부담이라는 서로 다른 필드이며 양립할 수 있다. `처방 산소 사용 중 산소포화도`와 `산소 없이 측정한 산소포화도`도 측정 조건이 다르므로 서로 대체하지 않는다.

같은 의미 필드와 조건을 직접 반증하는 자료가 있을 때만 충돌 후보가 된다. 서로 다른 필드가 어떻게 연결되는지 설명할 수 없다는 이유만으로 충돌이나 교정 제안을 만들지 않는다.

## 교정

같은 ID의 내용을 덮어쓰지 않는다. 새 fact ID를 만들고 `supersedes`와 승인 근거를 기록한다. 국소 오류는 파생 상태만 재계산한다. T0, 핵심 연표, 광범위한 인과망이 무너지면 마지막 유효 체크포인트와 보존 가능한 사실을 제시하고 사용자 결정을 기다린다.
