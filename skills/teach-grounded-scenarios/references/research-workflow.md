# 웹 조사와 연구 준비도

## 조사 순서

1. 학생 프로필에서 교과, 핵심 질문, 장소·시대·현상 범위, 최신성 요구를 추출한다.
2. 수업에서 사실로 사용하려는 핵심 주장 후보를 먼저 목록화한다.
3. 주장마다 필요한 자료 유형과 검색 질의를 정한다.
4. 검색 도구로 후보를 찾고 브라우저나 문서 도구로 실제 원문을 연다.
5. 원문이 직접 지지하는 범위와 지지하지 않는 범위를 기록한다.
6. 서로 독립적인 자료가 필요한 주장에는 교차 근거를 확보한다.
7. 충돌, 공백, 철회, 최신성 문제를 기록한다.
8. 연구 준비도 검사를 통과한 주장만 시나리오 카드에 사용한다.

## 웹 도구 사용 규칙

- 사용 가능한 검색, 브라우저, 논문, 데이터 도구를 활용한다.
- 검색 결과의 제목, 스니펫, 자동 요약만 인용하지 않는다.
- PDF나 데이터셋이 핵심 근거면 해당 문서의 실제 페이지, 표, 변수 설명을 확인한다.
- 출처 URL은 검색 결과 페이지가 아니라 주장을 뒷받침하는 원문으로 연결한다.
- 현재 정보는 조사 시각 또는 확인일을 기록한다.
- 웹 도구가 없거나 원문 접근이 막히면 조사를 완료했다고 주장하지 않는다.

## 주장 위험도

- `LOW`: 안정적인 정의, 널리 확립된 기초 사실, 단순 계산
- `MEDIUM`: 해석이 필요한 역사·사회 주장, 특정 조건의 과학 설명
- `HIGH`: 현재 법령·통계, 건강·안전, 논쟁적 역사, 새로운 과학 연구, 큰 수치

위험도가 높을수록 원문, 독립 출처, 기준 시점, 한계 설명을 강화한다. 위험도가 높다는 이유만으로 시나리오를 금지하지 않되 학생용 결론을 좁힌다.

## 연구 준비도 검사

다음을 모두 만족해야 시나리오 카드 단계로 이동한다.

- 교과 영역과 핵심 질문이 정해졌다.
- 핵심 사실 주장마다 직접 근거 또는 증명이 있다.
- 모든 출처가 실제 원문까지 열렸다.
- 출처의 기관, 유형, URL, 발행일 또는 미상 표시, 확인일, 한계가 기록됐다.
- 최신성이 필요한 자료는 현재 세션에서 확인됐다.
- 논쟁과 충돌이 숨겨지지 않았다.
- 설정과 미확인 내용을 사실과 구분했다.
- 다섯 시나리오 각각이 연구 팩의 주장 ID를 참조할 수 있다.

준비도가 부족하면 추가 조사, 범위 축소, 비사실형 문제 해결 활동, `UNKNOWN` 표시 중 하나를 선택한다.

## 금지 패턴

- 시나리오를 먼저 쓰고 나중에 맞는 출처를 찾기
- 출처 수가 많다는 이유만으로 합의를 주장하기
- 동일 보도자료를 전재한 여러 기사를 독립 근거로 세기
- 최신 연구 하나를 교과서적 합의로 표현하기
- 공식 기관의 설명이라는 이유로 자료의 시간·범위 한계를 생략하기
- 접근하지 못한 유료 논문의 초록만으로 세부 결과를 확정하기
