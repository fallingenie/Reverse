# 근거와 스토리 설정 정책

## 근거 레코드

각 핵심 주장은 식별자, 상태, 주장, 출처 식별자, 짧은 이유를 가진다.

### VERIFIED

기관 원문, 공식 기록, 검토된 교육 자료가 주장을 직접 지지할 때만 사용한다. 출처가 관련 있다는 이유만으로 직접 지지한다고 표시하지 않는다.

### DERIVED

검증된 사실 두 개 이상을 연결한 제한적 추론에 사용한다. 입력 사실의 ID와 추론 한계를 기록한다. “가능성이 있다”와 “그렇게 되었다”를 구분한다.

### SCENARIO

역할, 분기점, 가상 사건에 사용한다. 사실 자료와 같은 문단에 섞을 때는 `[가정]` 표지를 붙인다.

### UNKNOWN

자료가 없거나, 자료가 충돌하거나, 단일 결론이 없는 경우 사용한다. 임의의 확률이나 전문가 합의를 만들지 않는다.

## 모드별 설정 원칙

### 역사 역할 탐구

역할의 지식, 신분, 장소, 이동과 정보 접근을 당시 조건에 맞춘다. 재구성한 대화와 일상은 `SCENARIO`로 둔다.

### 반사실 탐구

1. 분기점을 한 문장으로 쓴다.
2. 분기점이 일어나기 전의 시간선은 실제 역사와 동일하게 둔다.
3. 분기점이 직접 바꾸는 사실만 먼저 변경한다.
4. 이후 결과는 한 단계씩 인과를 연결한다.
5. 행위자에게 당시 알 수 없었던 정보를 주지 않는다.
6. 결과가 여러 갈래면 하나를 정답으로 고정하지 않는다.

### 과학 현상과 실험

실험 조건, 독립·종속·통제 변인, 단위와 측정 오차를 명시한다. 관찰하기 전 결과를 확정하지 않는다. 위험하거나 불가능한 실험은 자료 분석이나 모형 활동으로 전환한다.

### 사회·지리 의사결정

이해관계자, 공간 범위, 예산·법·시간 제약을 유지한다. 특정 정책 선택을 유일한 도덕적 정답으로 만들지 않는다.

### 수학 문제 상황

이야기 요소가 정의, 조건, 계산 결과를 변경하지 않게 한다. 추측과 증명을 구분하고 반례 가능성을 확인한다.

### 문학 관점 탐구

텍스트에 적힌 내용, 역사적 배경, 해석을 분리한다. 학생의 해석은 텍스트 근거로 토론하되 하나의 숨은 정답으로 고정하지 않는다.

## 출처 우선순위

교과별 우선순위는 `domain-policies.md`, 권위 등급·독립 근거 수·논문 검사는 `source-quality.md`를 따른다. 공통적으로 원문·원자료, 직접 지지 범위, 발행일과 확인일, 한계를 기록한다.

블로그, 검색 요약, 생성형 모델의 이전 답변은 사실의 최종 근거로 사용하지 않는다.

## 충돌 처리

- 출처가 충돌하면 무엇이 충돌하는지 병렬로 적는다.
- 최신 자료라는 이유만으로 1차 사료의 존재를 지우지 않는다.
- 학생에게는 학년 수준에 맞게 “확인됨”, “해석”, “가정”, “아직 모름”으로 번역한다.
- 교정이 발생하면 기존 주장을 삭제하지 말고 교정 레코드로 연결한다. 영향 평가와 Story Track 처리는 `canon-repair.md`를 따른다.
