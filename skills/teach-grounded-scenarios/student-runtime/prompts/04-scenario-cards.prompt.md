# Prompt 04: 저위험 단원 시나리오 다섯 개

## 입력

- 확인된 학교급과 학년
- 학생이 선택한 과목
- 학생이 직접 입력한 구체 단원
- 현재 Context에 이미 제공된 교육과정 Knowledge snippet 또는 `없음`

## LOW_RISK_UNIT_BOOTSTRAP

카드 생성 전에 P0 안전·과학 무결성 게이트를 먼저 적용한다. 위해 또는 즉각 위험 신호가 있으면 카드 생성을 중단한다.

이 Prompt에서는 외부 검색 Skill과 도구를 호출하지 않는다. `search-before-answer`, 웹 검색, 브라우저, Knowledge 재검색, `analyzing-pdf`, PDF 전처리, 로컬 manifest·artifact·path·grep을 사용하지 않는다.

현재 Context에 직접 snippet이 있으면 그 snippet이 지지하는 단원 범위만 `사실 확인됨`으로 쓸 수 있다. 없으면 교육과정 일치를 `확인 필요`로 표시한다. 학생이 입력한 단원명은 학생 입력으로 기록하며 성취기준 번호, 쪽수, 교육과정 원문을 지어내지 않는다.

외부 사실 없이도 성립하는 학년 맞춤 탐구 상황을 정확히 다섯 개 즉시 만든다. 각 상황은 학생이 들어갈 시나리오 제안이다. 역사·과학·사회 사실을 카드의 전제로 넣지 않는다. 수학 단원이라면 수학적 정의와 학생에게 제시한 수치만 사용하되, 문제집 문항을 배경으로 포장하지 않는다. 학생이 맡을 역할, 구체적 장소·시간 또는 상황, 역할이 부딪힐 갈등, 당장 해결할 목표가 있는 제안으로 만든다. 각 카드의 내부 상태 `external_fact_required`는 `false`여야 한다.

수학 카드는 이후 수업의 `힌트 단계 → 학생 시도 → 과정 피드백 → 정답 공개` 순서를 보존한다. 카드 제목·갈등·목표·연결 개념·근거 경계에 최종 수치, 완성 계산식, 풀이 전체를 쓰지 않으며, 관찰 단서·인물 대사·행동 선택에 정답을 숨기거나 미리 누설할 장치도 넣지 않는다.

과학 카드는 `관찰 질문 1개 → 서로 다른 학생 예측·행동 2개와 직접 입력 → 학생 응답 → 실제 측정 또는 같은 블록 첫 문장에 수업을 위한 가정이라는 국소 선행 라벨을 붙인 가상 관찰 → 피드백 → 짧은 개념 연결` 순서를 예약한다. 학생 예측이 없으면 결과·결론을 연속 또는 먼저 제시하지 않는다. `계속`·자동 진행은 예측·선택·관찰이 아니다. 창의적 역할·장소·갈등은 유지하되 운송 성공 같은 결과는 `서사 결과 — 수업을 위한 가정`으로만 다룬다. 단원 직접 근거가 없으면 첫 장면의 교육과정 일치는 `확인 필요`다.

첫 카드부터 차례로 `1.`, `2.`, `3.`, `4.`, `5.`를 제목 앞에 붙인다. 실제 선택 버튼을 지원하면 같은 다섯 제목을 버튼으로 제공한다.

```text
N. 제목
- 역할: 학생이 장면에서 맡을 구체적 역할
- 장소·때: 장면이 벌어질 구체적 장소와 시간 또는 상황
- 갈등과 목표: 지금 해결해야 할 문제와 행동 목표
- 연결 개념: 행동 뒤 짧게 연결할 입력 단원 개념
- 근거 경계: 학생 입력 단원 / 이미 제공된 직접 snippet / 확인 필요 / 수업 가정
```

다섯 카드 뒤에 다음을 출력한다.

```text
번호를 고르거나, 원하는 시나리오를 한두 문장으로 직접 적어 주세요.
```

카드를 제시하는 것은 장면 시작이 아니다. 학생이 카드를 선택한 뒤 선택한 카드에 외부 사실이 필요하면 Prompt 02로 이동한다. 필요하지 않으면 선택을 확인하고 시작 여부를 묻는다.

## 검사

- 카드가 정확히 다섯 개인가?
- 외부 검색이나 PDF 분석을 호출하지 않았는가?
- 각 카드가 학생 입력 단원만으로 성립하는가?
- 카드마다 역할, 장소·때, 갈등과 목표, 근거 경계가 있는가?
- 문제집 제목이나 정답 고르기를 배경으로 포장하지 않았는가?
- 수학 카드에 최종 수치·완성 계산식·풀이 전체 또는 숨은 정답이 없는가?
- 과학 카드가 학생 예측 전에 가상 결과·결론을 공개하지 않는가?
- 검증하지 않은 교육과정 일치와 외부 사실을 `확인 필요`로 표시했는가?
- 성취기준 번호·쪽수·원문 문구를 만들지 않았는가?
- 장면·대사·결과를 시작하지 않았는가?
