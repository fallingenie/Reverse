# Prompt 02: 선택된 시나리오의 필요 주장만 조사

## 실행 전제

다음 조건을 모두 만족할 때만 이 Prompt를 실행한다.

- 학생이 다섯 카드 중 하나 또는 직접 입력 시나리오를 선택했다.
- P0 안전·과학 무결성 게이트를 통과했다.
- 선택한 시나리오가 외부 역사·과학·사회 사실을 실제로 필요로 한다.

하나라도 만족하지 않으면 외부 검색 Skill과 도구를 호출하지 않는다. `LOW_RISK_UNIT_BOOTSTRAP`, 단원 확인, 카드 생성 단계에서는 이 Prompt를 실행하지 않는다. 순수 수학 계산·관찰·문제 상황처럼 학생 입력 단원만으로 성립하는 카드는 조사 없이 선택 확인으로 이동한다.

## 입력

- 학년, 과목, 단원
- 학생이 선택한 시나리오 하나
- 그 시나리오에서 외부 검증이 필요한 주장 후보

## 지시

선택되지 않은 나머지 네 카드까지 조사하지 않는다. 필요한 주장만 다음 구조로 분류한다.

1. `subject_domains`
2. `essential_question`
3. `claim_candidates`
4. `freshness`
5. `risk`
6. `required_source_classes`
7. `claim_quality_gates`
8. `search_queries`

필요한 경우에만 웹 검색과 브라우저 도구로 후보 자료를 찾고 실제 원문을 연다. 검색 결과 요약은 후보 발견에만 사용한다. 원문 검증이 끝나지 않은 주장은 `확인 필요`로 유지한다. 확인할 수 없으면 사실을 만들지 말고 외부 사실이 필요 없는 범위로 선택 시나리오를 줄이거나 다른 안전한 카드 선택을 제안한다.

## 금지

- 단원명 확인을 위해 `search-before-answer` 또는 `analyzing-pdf`를 실행하기
- 카드가 선택되기 전에 검색하기
- 다섯 카드 전체를 선제 조사하기
- 교육과정 PDF 한 문장을 최신 과학·논쟁적 역사 사실의 자동 권위로 사용하기
