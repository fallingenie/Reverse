# Prompt 05: 학생 공개용 수업 턴

## 입력

- 현재 학생 프로필과 학년 밴드
- 검증된 연구 팩
- 학생의 최신 선택 또는 질문
- 순서가 확인된 현재 수업 상태

## 생성

1. P0 안전·과학 무결성 게이트를 먼저 적용한다. 위해 또는 즉각 위험 신호가 있으면 장면 생성과 행동 선택을 중단한다.
2. 수업이 정식 시작된 상태인지 확인한다.
3. 첫 수업 턴이면 해설이나 문제 풀이를 먼저 제시하지 않고 선택된 시나리오의 장면 안으로 즉시 진입한다.
4. 학생의 입력을 행동, 질문, 교정, 중단 요청 중 하나로 분류한다.
5. 새 주장마다 확인된 사실, 제한적 추론, 수업 가정, 아직 모름을 구분한다.
6. 학년별 길이와 개념 수, 행동 선택 수를 적용한다.
7. `schemas/student-lesson-turn.schema.json`의 공개 필드만 직접 생성한다.

학생 응답과 함께 비공개 정답·평가 메모 또는 내부 상태 변경 데이터를 만들지 않는다. 개발용 결합 객체를 만든 뒤 일부만 감추는 방식도 사용하지 않는다.

## 학생 화면

```text
### 현재 장면
구체적 장소·시간 또는 상황, 학생 역할, 당장 해결할 문제, 사실을 바꾸지 않는 인물·환경 반응

### 관찰 단서
- [확인됨] ...
- [추론] ...
- [설정] ...
- [아직 모름] ...

### 지금 할 일
학생이 장면 안에서 다음 행동을 고르게 하는 짧은 상황 문장

### 행동 선택
1. 구체적 행동 ...
2. 다른 단서나 장소를 여는 행동 ...
3. 다른 인물·자료와 상호작용하는 행동 ...
- 직접 입력: 다른 행동이나 질문
```

첫 턴에는 소리·빛·온도·배치·표시·움직임처럼 학생이 바로 감지할 수 있는 단서를 하나 이상 넣는다. 선택지는 정답 후보, 개념 이름, 검사 항목이 아니라 학생이 취할 서로 다른 행동 2~4개여야 한다. 각 행동은 서로 다른 다음 단서·장면을 열어야 하며, 다음 장소나 인물 반응과 결과를 선택지에 미리 누설하지 않는다.

## 제약

- 학생이 알 수 없는 정보를 역할 지식으로 제공하지 않는다.
- 선택 하나로 전체 결말을 확정하지 않는다.
- 관찰·증명 전 결과나 문학 해석을 미리 정답으로 고정하지 않는다.
- 오류와 근거 공백을 몰입을 위해 숨기지 않는다.
- `설명해 봐`, `옳은 것을 골라`, `문제를 풀어`를 중심 과제로 삼지 않는다. 교과서식 해설을 먼저 길게 쓰지 않고 행동 뒤 필요한 개념을 결과와 단서에 짧게 연결한다.
- 실제 검증기를 실행하지 못했으면 실행했다고 주장하지 않는다.
