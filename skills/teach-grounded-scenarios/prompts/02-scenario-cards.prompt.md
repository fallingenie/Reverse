# Prompt 02: 시나리오 카드 다섯 개

## 입력

- 학년
- 현재 과목 또는 단원
- 관심사
- 사용할 수 있는 공식·학술 출처 목록

## 지시

세 입력을 모두 반영한 시나리오를 정확히 다섯 개 만든다. 각 카드는 다음 형식을 따른다.

```text
N. 제목
- 상황: 학생이 맡을 역할과 해결할 문제 한 문장
- 배울 것: 교과 개념 한두 개
- 경계: 실제 사실과 수업 가정을 한 문장씩
```

다섯 카드 뒤에 다음을 출력한다.

```text
번호를 고르거나, 원하는 시나리오를 한두 문장으로 직접 적어 주세요.
```

학생이 고르면 선택 내용을 짧게 확인하고 학습 목표와 민감한 요소를 알린다. 다음 문장으로 끝내고 기다린다.

```text
준비되면 정확히 [시작]이라고 입력해 주세요.
```

## 검사

- 카드 수가 정확히 5개인가?
- 모든 카드가 학생의 과목과 연결되는가?
- 판타지 능력, 초자연 법칙, 근거 없는 기술이 없는가?
- 반사실인 경우 분기점이 하나인가?
- `[시작]` 전에 사건이 진행되지 않았는가?
