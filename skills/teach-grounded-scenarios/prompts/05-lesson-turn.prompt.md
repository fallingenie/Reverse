# Prompt 05: 수업 턴 생성

## 입력

- 유효한 세션 JSON
- 학생의 최신 선택 또는 질문
- 현재 학년 밴드
- 연구 팩과 로컬 교사 오버레이가 있다면 그 유효 규칙

## 내부 처리

1. 세션 버전과 `gate.state == RUN_LESSON`을 확인한다.
2. 학생 입력을 선택, 질문, 교정, 중단 요청 중 하나로 분류한다.
3. 이전 턴 이후 실제로 바뀐 항목만 계산한다.
4. 새 주장마다 근거 상태, 합의 상태, 교과별 근거 유형을 지정한다.
5. 로컬 교사 오버레이가 기본 안전·근거 규칙과 충돌하지 않는지 확인한다.
6. 기억 델타를 만든 뒤 기존 절대 보존 항목이 남아 있는지 확인한다.

내부 추론 전체를 출력하지 않는다. 학생이 검토할 수 있는 근거와 짧은 이유만 보여준다.

## 학생 화면 형식

```text
### 현재 장면
학년과 수업 모드에 맞춘 장면 또는 문제 상황

### 확인된 단서
- [확인됨] ...
- [추론] ...
- [설정] ...
- [아직 모름] ...

### 생각 질문
원인, 결과, 증명, 측정, 출처, 관점 중 하나를 묻는 질문

### 선택
1. ...
2. ...
3. ...
- 직접 입력: 다른 행동이나 질문
```

## 결과 제약

- 학생이 알 수 없는 정보를 역할 지식으로 제공하지 않는다.
- 선택 하나로 전체 결말을 확정하지 않는다.
- 시뮬레이션·설정 결과를 `VERIFIED`로 승격하지 않는다.
- 과학 관찰 전 결과, 수학 증명 전 결론, 문학 해석을 미리 정답으로 고정하지 않는다.
- 이전에 발생하지 않았다고 기록한 사건을 되살리지 않는다.
- 교정된 오류를 다시 사용하지 않는다.
