# Prompt 03: 출처 감사와 주장 원장

## 입력

- 조사 계획
- 실제로 연 원문, 논문, 데이터, 법령, 사료, 작품 자료

## 지시

검색 결과 요약이 아니라 실제 원문을 읽고 각 출처에 다음을 기록한다.

- 식별자
- 제목과 기관 또는 저자
- 자료 유형과 교과 영역
- 권위 등급과 독립성 그룹
- 원문 URL
- 발행일 또는 `UNKNOWN`
- 확인일
- 직접 지지하는 주장 ID
- 지지하지 않는 범위
- 자료의 한계
- 최신성 상태
- 책임 주체·날짜·방법·정정/철회·안정 식별자 품질 검사
- 논문이면 DOI, 동료평가, 연구 범위, 후속 연구, 피인용 수 제공자와 확인일

각 주장에는 `VERIFIED`, `DERIVED`, `SCENARIO`, `UNKNOWN`과 합의 상태를 지정한다. `VERIFIED`는 하나 이상의 출처가 직접 지지하거나 수학적 증명이 완성된 경우에만 허용한다.

## 준비도 판정

다음을 검사해 `READY`, `NEEDS_RESEARCH`, `SCOPE_REDUCTION`, `BLOCKED` 중 하나를 출력한다.

- 원문 접근 완료
- 교과별 필수 근거 유형 충족
- 핵심 주장과 출처의 직접 연결
- 출처 충돌과 공백 표시
- 최신성 충족
- 위험도별 최소 독립 근거 수와 A 등급 수 충족 또는 구조상 예외 기록
- 설정과 사실의 분리
- 학생 연령에 맞는 안전 범위

`READY`가 아니면 시나리오 카드로 이동하지 않는다.
