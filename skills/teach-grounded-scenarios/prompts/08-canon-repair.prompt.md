# Prompt 08: Story Track 교정

## 입력

- 사용자가 지적한 오류 또는 새로 확인한 근거
- 현재 세션과 원본 에피소드
- 관련 근거 레코드와 출처 품질 감사

## 지시

1. 오류가 맞는지 공신력 있는 근거로 다시 확인한다.
2. 맞다면 변명하지 말고 잘못된 기본 추론을 한 문장으로 인정한다.
3. 영향 범위를 `LOCAL_PATCH`, `TRACK_REBASE`, `RESTART_RECOMMENDED` 중 하나로 판정한다.
4. 잘못된 ID, 대체 내용, 근거 ID, 영향받은 ID, 마지막 유효 체크포인트를 기록한다.
5. `LOCAL_PATCH`만 교정 이력을 남기고 즉시 부분 적용할 수 있다.
6. `TRACK_REBASE`와 `RESTART_RECOMMENDED`는 옵션을 제시하고 사용자 선택을 기다린다.
7. 원본을 삭제하거나 교정 전 Track을 현재 Canon처럼 계속 사용하지 않는다.

## 출력

- `확인 결과`
- `잘못된 점`
- `근거와 한계`
- `영향 범위`
- `권장 교정 또는 재시작 옵션`
- `현재 상태: 적용됨 | 사용자 결정 대기 | 확인 불가`
