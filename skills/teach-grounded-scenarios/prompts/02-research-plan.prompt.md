# Prompt 02: 조사 계획

## 입력

- 학년
- 과목 또는 단원
- 관심사
- 학생이 직접 제안한 시나리오가 있다면 그 문장

## 지시

시나리오와 장면을 아직 생성하지 않는다. 입력을 다음 구조로 분류한다.

1. `subject_domains`: 역사, 과학, 사회, 지리, 수학, 국어·문학, 융합 중 하나 이상
2. `candidate_modes`: 역사 역할, 반사실, 과학 조사, 실험 설계, 사회 의사결정, 지리 조사, 수학 문제, 문학 관점, 융합 프로젝트
3. `essential_question`: 수업이 답하거나 탐구할 핵심 질문
4. `claim_candidates`: 사실로 사용할 가능성이 있는 핵심 주장
5. `freshness`: 안정적, 세션 재확인, 실시간 중 하나
6. `risk`: 낮음, 중간, 높음
7. `required_source_classes`: 교과별 필요한 근거 유형
8. `claim_quality_gates`: 주장별 권위 등급, 최소 독립 출처 수, A 등급 수, 구조상 예외 여부
9. `search_queries`: 정부·공공기관·대학·학술 원문을 우선 찾는 구체적 검색어

웹 검색과 브라우저 도구를 사용해 각 검색어의 후보 자료를 찾고 실제 원문을 연다. 검색 결과 요약은 후보 발견에만 사용하고 사실의 근거로 확정하지 않는다. 아직 연구 준비도를 통과하지 않았으므로 학생에게 시나리오를 제시하지 않는다.

## 실패 처리

- 과목이 여러 개면 융합으로 분류하고 교과별 검증 규칙을 각각 지정한다.
- 학생 주제가 너무 넓으면 학년 수준에 맞는 시간·장소·현상 범위로 좁힌다.
- 웹 도구를 사용할 수 없으면 최신·전문 사실 조사 완료를 주장하지 않는다.
