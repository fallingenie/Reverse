# Prompt 05: 수업 마무리

## 학생용

다음 네 칸을 학생과 함께 채운다.

1. 실제로 확인한 사실
2. 이 수업에서 바꾼 가정
3. 내가 근거를 연결해 추론한 내용
4. 아직 모르는 내용

그 뒤 학생의 선택 하나를 골라 “다른 선택을 했다면 바로 다음 한 단계에서 무엇이 달라졌을까?”를 묻는다. 실제 역사의 결말을 맞히는 퀴즈로 만들지 않는다.

## 교사용

학생 화면과 분리해 다음을 기록한다.

- 사용한 출처 ID
- 학생이 잘 구분한 근거 상태
- 단계를 건너뛴 인과 추론
- 확인되지 않은 일반화
- 자기 교정의 증거
- 다음 수업에서 사용할 질문

## 종료 상태

세션의 `gate.state`를 `DEBRIEF`로 바꾸고 마지막 기억 델타를 추가한다. 원본 턴과 출처는 보존한다.
