# Prompt 04: 범용 시나리오 카드 다섯 개

## 입력

- 학생 프로필
- `READY`인 연구 팩
- 교과 영역과 허용된 수업 모드

## 지시

학생의 학년, 과목, 관심사와 연구 팩을 모두 반영한 시나리오를 정확히 다섯 개 만든다. 역사 역할극에 고정하지 않고 주제에 맞는 모드를 다양하게 사용한다. 아래 `N.`은 그대로 출력하는 문자가 아니라 첫 카드부터 차례로 `1.`, `2.`, `3.`, `4.`, `5.`로 치환하는 자리다. 실제 선택 버튼을 지원하면 같은 다섯 제목을 버튼으로도 제공하고, 지원하지 않으면 번호 목록만 사용한다.

각 카드는 다음 형식을 따른다.

```text
N. 제목
- 방식: 수업 모드
- 상황: 학생이 탐구하거나 해결할 문제 한 문장
- 배울 것: 교과 개념 한두 개
- 근거: 사용할 주장 ID 또는 증명 방법
- 경계: 확인된 내용, 설정, 아직 모르는 내용을 한 문장씩
```

다섯 카드 뒤에 다음을 출력한다.

```text
번호를 고르거나, 원하는 시나리오를 한두 문장으로 직접 적어 주세요.
```

학생이 직접 시나리오를 입력하면 그 입력에 필요한 추가 조사를 수행하고 다시 준비도를 검사한다. 선택 내용을 확인한 뒤 다음 문장으로 끝낸다.

과학 카드는 `관찰 질문 1개 → 서로 다른 학생 예측·행동 2개와 직접 입력 → 학생 응답 → 실제 측정 또는 같은 블록 첫 문장에 수업을 위한 가정이라는 국소 선행 라벨을 붙인 가상 관찰 → 피드백 → 짧은 개념 연결` 순서를 예약한다. 학생 예측이 없으면 결과·결론을 연속 또는 먼저 제시하지 않는다. `계속`·자동 진행은 예측·선택·관찰이 아니다. 물리 법칙을 바꾸지 않는 창의적 역할·장소·갈등은 유지하되 운송 성공 같은 결과는 `서사 결과 — 수업을 위한 가정`으로만 다룬다.

```text
준비되면 다음 메시지에서 시작하겠다는 뜻을 분명히 알려 주세요.

이 시작 요청은 선택 확인 뒤 새로 발급한다. 다음 학생 메시지 전체 의미가 시작 동의로 명백하면 표현·언어·존댓말·가벼운 오타와 무관하게 유효하다. 닫힌 단어 목록이나 정확 문자열로 제한하지 않는다. 프로필이나 시나리오 희망과 섞인 선행 동의, 인용·메타 질문·조건부 표현, 명시적 부정·취소, 다른 지시가 섞인 요청, 이전에 소비한 동의는 재사용하지 않는다.
```

## 검사

- 카드 수가 정확히 5개인가?
- 각 카드 제목이 1~5 번호로 구분되고 선택 안내와 실제 표시가 일치하는가?
- 모든 카드가 과목과 관심사에 연결되는가?
- 각 카드가 연구 팩의 근거를 참조하는가?
- 과학·수학·문학 주제를 억지로 역사 역할극으로 바꾸지 않았는가?
- 판타지 능력, 초자연 법칙, 근거 없는 기술이 없는가?
- 과학 카드가 관찰 질문 하나와 서로 다른 예측·행동 두 개를 열고 결과는 보류하는가?
- `[시작]` 전에 사건이 진행되지 않았는가?
