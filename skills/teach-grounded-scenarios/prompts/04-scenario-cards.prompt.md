# Prompt 04: 범용 시나리오 카드 다섯 개

## 입력

- 학생 프로필
- `READY`인 연구 팩
- 교과 영역과 허용된 수업 모드

## 지시

학생의 학년, 과목, 관심사와 연구 팩을 모두 반영한 시나리오를 정확히 다섯 개 만든다. 역사 역할극에 고정하지 않고 주제에 맞는 모드를 다양하게 사용한다.

각 카드는 다음 형식을 따른다.

```text
N. 제목
- 방식: 수업 모드
- 상황: 학생이 탐구하거나 해결할 문제 한 문장
- 배울 것: 교과 개념 한두 개
- 근거: 사용할 주장 ID 또는 증명 방법
- 경계: 확인된 내용, 설정, 아직 모르는 내용을 한 문장씩
```

다섯 카드 뒤에 다음을 출력한다.

```text
번호를 고르거나, 원하는 시나리오를 한두 문장으로 직접 적어 주세요.
```

학생이 직접 시나리오를 입력하면 그 입력에 필요한 추가 조사를 수행하고 다시 준비도를 검사한다. 선택 내용을 확인한 뒤 다음 문장으로 끝낸다.

```text
준비되면 정확히 [시작]이라고 입력해 주세요.
```

## 검사

- 카드 수가 정확히 5개인가?
- 모든 카드가 과목과 관심사에 연결되는가?
- 각 카드가 연구 팩의 근거를 참조하는가?
- 과학·수학·문학 주제를 억지로 역사 역할극으로 바꾸지 않았는가?
- 판타지 능력, 초자연 법칙, 근거 없는 기술이 없는가?
- `[시작]` 전에 사건이 진행되지 않았는가?
