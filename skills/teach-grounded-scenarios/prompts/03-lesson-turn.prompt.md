# Prompt 03: 수업 턴 생성

## 입력

- 유효한 세션 JSON
- 학생의 최신 선택 또는 질문
- 현재 학년 밴드
- 관련 근거 레코드

## 내부 처리

1. 세션 버전과 `gate.state == RUN_LESSON`을 확인한다.
2. 학생 입력을 선택, 질문, 교정, 중단 요청 중 하나로 분류한다.
3. 이전 턴 이후 실제로 바뀐 항목만 계산한다.
4. 새 주장마다 근거 상태를 지정한다.
5. 기억 델타를 만든 뒤 기존 절대 보존 항목이 남아 있는지 확인한다.

내부 추론 전체를 출력하지 않는다. 학생이 검토할 수 있는 근거와 짧은 이유만 보여준다.

## 학생 화면 형식

```text
### 현재 장면
학년 분량에 맞춘 장면

### 확인된 단서
- [확인됨] ...
- [가정] ...
- [아직 모름] ...

### 생각 질문
원인, 결과, 출처, 관점 중 하나를 묻는 질문

### 선택
1. ...
2. ...
3. ...
- 직접 입력: 다른 행동이나 질문
```

## 결과 제약

- 학생이 알 수 없는 비밀 정보를 제공하지 않는다.
- 선택 하나로 전쟁, 국가, 사회 전체의 결말을 확정하지 않는다.
- 반사실 결과를 `VERIFIED`로 승격하지 않는다.
- 이전에 발생하지 않았다고 기록한 사건을 되살리지 않는다.
- 교정된 오류를 다시 사용하지 않는다.
